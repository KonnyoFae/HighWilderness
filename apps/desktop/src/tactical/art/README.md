# 战术画布临时美术资源

这五份 SVG 是程序生成纹理的可替换临时素材，不是最终美术验收稿；不包含外部图片或网络依赖。

| 观察层 | 背景 | 前景 |
| --- | --- | --- |
| 上层 | `upper-cloud-sea.svg` 浅色云海 | 无 |
| 云层 | `cloud-sea.svg` 灰暗云海 | `cloud-foreground.svg` 半透明浅色云海 |
| 雨层 | `rain-cloud-sea.svg` 深色云海 | `rain-foreground.svg` 重复雨丝 |

接入入口是 `../atmosphere.ts` 中的 `TACTICAL_LAYER_ART`。背景和前景分别配置 URL、透明度、重复纹理尺寸及镜头视差。可将本地 PNG/WebP 等素材放入此目录并在配置文件中导入替换，也可继续使用 SVG。雨前景的滚动速度由 `scrollPixelsPerSecond` 定义；只读取共用显示时间，暂停与隐藏不另运行天气计时器。

云海图像可以替换成可平铺贴图。雨图的重复边缘应连续，透明前景需保留 Alpha。当前云纹理由 SVG 噪声生成并在加载时解码为纹理，持续绘制时不重新运行噪声滤镜。图像资源由各战场视图单独持有，离场销毁；缺失素材退回基底色并显示提示，不阻塞战斗与镜头操作。

叠放顺序是背景 → 世界距离网格 → 舰体 → 云/雨前景 → 炮向、弹体与目标标记；坐标文字和舰名显示在画布上方。50/500/5,000 米网格由 `distanceGrid.ts` 计算，不随美术贴图尺寸变化。火控与传感器不读取纹理像素。
