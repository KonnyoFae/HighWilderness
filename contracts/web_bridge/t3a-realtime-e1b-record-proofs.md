# E1b：步内不可变状态与计算结果的验证复用

日期：2026-09-08。状态：`E1b_IMPLEMENTED / E1_IN_PROGRESS / REALTIME_NOT_PASSED`。

本片将“无变化不重复校验”落实到独立飞行会话的内部对象传递。默认桌面仍未切换实验后端，编辑器及外部 JSON 解析语义不变。

## 实现范围

新增 `高天荒野舰艇内部步骤证明.py`，在一次权威固定步内保存精确对象身份与强引用。普通内部状态第一次仍严格解析；对象及其嵌套成员经不可变检查后，同一步内继续传递时直接复用解析结果。保留解析后的规范化对象，避免改变旧解析返回值。

接入发动机状态、整舰推进状态、控制、硬故障投影/适配、方向互锁和整舰安全入口。不同对象不继承证明，即使内容相同也重新检查。动态时钟、可用性、权限、互锁、目标上限和安全计算仍正常执行，不能用结构解析通过替代这些依赖时间或环境的判断。

时间预览由共享生产函数完成原有检查后登记来源；提交仍检查当前状态和固定步，并要求同一能力对象。满足这些条件才省去重复生成预览。外部解析得到的预览、新副本、能力变化以及跨步/跨会话对象都不继承生成证明，走原严格重放或拒绝路径。

完整步首结果由共享生产函数完成组成和来源链检查后登记为内部结果，积分与收边界直接消费；普通构造或外部 parse 不会自动获得此证明。此次没有改写推进、损伤或配平公式，也没有关闭完整安全状态检查。

证明仅在当前固定步有效，退出作用域或异常时释放；不跨步缓存整舰动态状态，不接受客户端提交 trusted 标志。不变量相关写入仍由既有类型化计算产生新对象，跨步分域版本与完整战损依赖图继续留后续切片。证明不防御任意恶意 Python 反射修改。

只读图检查自身也按步内对象身份复用；类型字段描述缓存最多 256 项。第一轮曾因反复遍历子对象抵消了解析减少的收益，后续改为复用子图证明并让内部步首结果直接交付。保留三个实验目录，不能用首轮未提速结果宣称优化完成。
