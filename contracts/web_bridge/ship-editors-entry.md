# 舰艇编辑器启动入口

更新日期：2026-09-13。

双击项目根目录的 [启动舰艇编辑器.cmd](../../启动舰艇编辑器.cmd)，进入船壳 / 舾装编辑器选择页。

- **船壳编辑器**：填写名称并新建空白船壳，或打开已有船壳 JSON 文件。
- **舾装编辑器**：选择已保存的合法船壳来新建舾装，或打开已有舾装文件继续编辑。
- **返回入口**：编辑页点击“返回编辑器入口”。未保存修改会提示继续编辑或明确放弃；不会自动覆盖设计文件。
- 恢复草稿仍在入口页展示；内置示例分别收纳在两张卡片的折叠区。文件类型选错时按实际设计打开对应编辑器并说明；新建舾装误选已有舾装时明确引导使用“打开舾装文件”。

启动器使用现有桌面程序的专用编辑模式，仅加载编辑器；不创建或切换战斗场景，也不使用废弃测试台的数据或入口。普通程序启动保留原工作台导航。

首次启动或界面源码改变时自动构建，后续直接启动。需要本机项目开发依赖；源码校验和构建失败时明确停止，不继续启动旧版。源码增删与内容变化均纳入构建缓存检查。脚本为 [Start-ShipEditors.ps1](../../tools/Start-ShipEditors.ps1)，支持 `-BuildOnly` 仅构建。
