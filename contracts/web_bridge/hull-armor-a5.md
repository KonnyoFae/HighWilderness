# A5 结构与装甲联合验收、首轮数值基线

日期：2026-09-21。A0～A5工作包完成本轮设计、安装、战斗与保存范围，下一步为6c正式撤离、单舰离场和终局。此结论不是所有舰型的最终平衡或最大编制性能验收；密集弹体负载的余留性能项已列入工作包7。

## 数值基线与取舍

按现有规范舰建立可复算对照：155米双层船壳、固定设备及30兆牛升力，各层结构采用相同厚度，基底装甲为50毫米，改变基底倾角，上层装甲保持原样。完成16种结构/倾角组合、九种装甲材料的36种倾角组合，以及四种口径、三种现行弹种、四种倾角、三个来向和三个速度组成的3888条穿透计算。燃烧弹使用当前版本，不混用旧穿深。对照脚本与[完整数据](../../artifacts/hull-armor-a5-20260921/calibration.json)保留输入口径与派生指纹。

同一外形减薄结构会降低重量、惯量、结构耐久和建造材料，不影响装甲真实厚度、局部耐久、内部安装格或RCS。实际战斗验证：相同穿透造成相同结构伤害点数时，15毫米结构的完整度损失为50毫米的约3.33倍；装甲损伤相同。相同已装主发动机全速工作10秒后，薄结构舰速度更高，换层入战基准也更短。

增加外飘会增加实际板材、惯量、成本和装甲局部耐久，不会增加全舰结构耐久。非基底外飘占用露天格但不减少内部格。九种材料在同几何下保持相同RCS，防护、局部耐久、密度和成本分别读取既有系数，不用材料名称额外加隐身折扣。按标准化单位推力/力矩列出的机动比值仅作对照，不冒充额外安装了转向设备。

本轮保留已确认的15～100毫米、5毫米步长、连接结构20%，以及30°/45°/60°倾角；材料系数、甲弹系数和结构耐久尺度沿用当前原型。雷达参考值维持1000平方米：A4的普通155米舰艏向接近该基准，满足现有距离作为基准、特大反射可超出的规则。没有证据支持为了让某一档全面占优而修改全局系数，最终装备/舰型平衡继续工作包7。旧设计厚度不自动调整。

## 玩家反馈与流程

编辑器新增默认折叠的“结构与装甲”，船壳和舾装共用后台结果：结构质量、基础装甲质量、各层厚度、外飘边数和被占用露天格数。提示减薄会降低结构耐久，外飘按真实板材计重且禁止侧挂；无效草稿明确标示沿用最近合法的质量、升力及外形结果。

真实页面完成基底50毫米/上层30毫米与上层45°外飘组合的编辑、撤销/重做、保存、重开及舾装。原100毫米样本需两个储罐，新组合一个储罐已能满足升力，页面据实际结果更新；再添加第二个储罐仍正常保存。另用25毫米结构与基底60°外飘舰完成双方准备、入战、运行暂停、保存全部战果和返回准备。[编辑报告](../../artifacts/hull-armor-a5-editor-final-20260921/report.json)、[编辑截图](../../artifacts/hull-armor-a5-editor-final-20260921/armor-editor.png)、[战斗往返报告](../../artifacts/hull-armor-a5-battle-20260921/report.json)。

后端同时验证组合设计的真实受击、自动装填扣料、战果保存、重启和第二场读取，不恢复战损或退回已消耗材料。升力不足的厚结构/大倾角组合正确拒绝，装甲承载不能替代升力。

## 联合负载发现与修复

冻结29炮双舰测试在100米/秒起步、持续加速、6公里接敌、完整弹仓下触发旧256 KiB响应上限。第137步显示数据约264397字节，主要为弹体轨迹，不是指令回执积压。[定位记录](../../artifacts/hull-armor-a5-20260921/response-budget-diagnosis.json)。

- 显示轨迹按时间插值误差压缩，保留出生、终点及转弯/加减速所需采样，原逐步历史不变；压缩前后插值误差不超过5厘米。仅按几何共线压缩会抹掉直线加速，因此明确按时间比较。
- 所有活动弹体继续传输，物理弹道、命中、射速、寿命和库存不变；不丢弃模拟步。已经结束轨迹的原保留时长和数量上限不变。
- 实时响应硬预算由256 KiB改为1 MiB，仍低于8 MiB桥接帧及16 MiB队列限制；战后结果维持4 MiB。压缩后实测峰值约383 KB，原预算仍不足，所以同时修正容量。
- 当前回归包含300条显示轨迹不丢身份、不修改源历史、直线加速/曲线误差和硬预算拒绝；真实29炮对照也不再发生响应超限。

最终对照在原无装甲测试舰艏部增加相同20毫米装甲，每舰两条艏边分别保持竖直或改45°，侧挂边保持竖直，确保外飘实际启用。竖直/外飘分别执行403/395步，发射215/211发，最多189/183个在途弹体；战局自然结束，因此不是120秒持续验收。[负载结果](../../artifacts/hull-armor-a5-20260921/workload.json)。

固定步平均约17.01/16.98毫秒，P95约28.88/28.52毫秒；外飘未增加明显计算负担，但这组密集弹量本身超出稳定60 Hz余量，近防威胁预测是主要开销之一。后续工作包7须处理该负载及发布/读取开销，保留案例复验，不能宣称已解决全部模拟落后。A5没有放宽模拟积压阈值。
