## 已实现范围

- `backend/high_wilderness_sidecar/simplified_propulsion.py`：独立规范化设计输入、严格快照/目录适配器、稳定发动机索引、完好基准和六方向贡献表。
- 数据只取编辑器的原始执行器、精确目录能力和固定应用点；不取 runtime 耐久效率、旧配平 use 或按配平结果生成的方向绑定。校验快照指纹、目录身份、模块/执行器对应关系、能力版本与排程、有限数、方向和深层只读。
- 平移发动机只进入四个平移方向；转向发动机按设计 CIC 原点的固定力臂计算有符号力矩，只进入对应转向方向。零力矩转向设备保留索引但贡献为零；当前政策只支持正交单位推力方向，其他方向明确拒绝。
- 编译采用十进制来源数值的精确有理运算，落盘为公共整数刻度：`实际量 = contribution_units / unit_denominator`。刻度取所有贡献分母的最小公倍数，不量化舍入。力和力矩分别标记 N、N*m；质量/惯量与响应秒数也保存精确分子/分母。
- 响应同时保存启动/响应步数和精确秒数，避免 1.01 秒响应仅存成 61 步而失去原排程语义。运行到期队列尚未实现。
- `remaining(available_ids)` 是严格的离线全量求和参考：分母始终为完好总量，支持空舰、全毁和初始受损选择；无对应方向时为零且标记不存在。不读取血量，不实现事件或差量更新。
- `CompiledFlightResources.simplified_propulsion` 存放只读贡献表。旧公共表现/回放资源导出保持原范围；新表通过专用离线导出展示，不冒充旧推进审计。

## 下一片的安全映射清单

以下是已冻结的接线责任，状态均为“新飞行内核待接线”，不是本片安全运行验收。

| 条件/旧原因 | 新政策处理与入口 | 后续验收 |
| --- | --- | --- |
| 配平分配、主机偏航、转向机残余平移 | 从新政策删除；编译器不读取旧分配输出 | 偏置/单侧损毁不降低健康机能力、不交叉输出 |
| `actuator_destroyed` | 毁伤生产者发失效事件；部分掉血不直接缩放贡献 | 损毁归零、无重复扣减；E2 接真实生产者 |
| `host_destroyed` | 固定宿主标识接依赖事件，合并失效原因 | 宿主未恢复时修复发动机不恢复推力 |
| `power_unavailable` | 供电域事件更新相关设备原因 | 多原因叠加；恢复不绕过其他原因 |
| `crew_unavailable` | 人员域保留可用性条件，以事件同步 | 失去必要人员禁止输出，不套用血量曲线 |
| `fuel_unavailable` | 保留燃料可用性条件；战术燃料燃烧仍为零 | 无燃料与不消耗燃料分别验证 |
| `engine_tripped`、紧急断推与复位 | 独立设备故障/模式原因，不经过配平 | 故障立即断开后续贡献，复位按原条件和启动规则 |
| `direction_interlock` | 六通道对向关系和当前输出检查 | 反转、制动及到期同边界不越过互锁 |
| 启动、响应、到期前改令 | 使用精确时间参数/阶段，在必要边界处理 | 不早到期、不恢复即满输出 |
| `structure_limit` | 结构载荷判定保留，输入改为新合力/合力矩和当前运动 | 逐项提取旧计算条件；无法接入时阻塞相应验收 |
| `crew_limit` 与 OverG 政策 | 保留乘员载荷条件和既有覆盖规则，输入改为汇总运动负载 | 不用“无配平”关闭乘员安全 |
| I9 权限、生命周期与数值/时序不变量 | 接新紧凑阶段输入，保留执行时检查与原子提交 | 越权/退出拒绝、失败候选不污染已提交边界 |

保留项不通过时 E1c.2/E2 不得宣称完整飞行规则已接齐。以后若改变人员效率或安全公式，须作为另外的明确规则变更记录。
