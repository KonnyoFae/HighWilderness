# H5d 整层防火与燃烧弹接续规划

日期：2026-09-11。状态：`H5D_SCOPED_PASS / O4_NATIVE_EVIDENCE_PENDING`。H5d.1—H5d.4 已范围内完成，实际规则、技术数值、验证与用户测试步骤见[实施记录](./h5d-fireproof-ignition.md)。以下保留实施时的切片和设计依据。本文件细化[统一交付顺序](./editor-tactical-delivery-roadmap.md)的第 9 项，完成范围以实施记录为准，原生窗口留档仍待收尾。

## 已确认规则与实现边界

用户确认：防火填充直接降低整层起火概率；货物燃烧不纳入当前或后续默认待办。每层所有边缘空间共用一种填充配置，同层分离区域也共用防火效果，不需要为每个片区计算覆盖率。

防火仅作用于新的点燃尝试，不改变已经存在的火势、燃烧时长、每步烧伤、自然衰减、灭火效率或损管资源成本。它不是每步持续减伤，也不赋予全舰免疫。此前提出的局部覆盖、按填充量连续缩放、随船壳完整度衰减和独立填料耐久均不进入首版。

首版工程口径：防火材料为固定填料，沿用已有质量/惯量；没有消耗库存、装填、维修或额外动态状态。配置为防火且本层实际可用填充净体积大于零时，启用该层统一防火系数；零净体积不给增益。无需按模块或填充片区累计效果。上述细化是实现默认，减概率系数及燃烧弹基础点燃率在实施时以版本化技术值冻结，之后可调，不视为正式平衡数值。

`实际起火概率 = 点燃来源基础概率 × 本层概率倍率`

普通层倍率为 1，防火层倍率为 0 到 1 之间的技术参数；例如 0.5 表示概率减半，不是减去 50 个百分点。首版不凭空给普通弹和穿甲弹增加点火能力。成功点燃后直接进入已有 D1 火灾过程。

- S1 已有普通/穿甲弹、配方预留和扣费、实际弹种、战前预装、战中下一批选择及跨场余弹保存。燃烧弹需要补真实效果及对应高能燃料货物配方。
- H5c 已有灵烷槽余量和独立槽损毁。弹药配方的高能燃料货物与灵烷槽库存分开记账，不从燃料槽扣装填成本，不恢复发动机耗油。

## 点燃事件的技术口径

1. 首种燃烧弹沿用实际碰撞及装甲判定，建议工程默认只对穿甲后实际命中的、结算后仍有耐久的内部模块产生点燃尝试；不增加范围爆炸、表面引燃或自动蔓延。未命中内部模块不伪造船壳火情。具体伤害/起火参数与配方成本在 H5d.2 冻结。
2. 现有火情以模块为身份。首版将模块安装基准层作为起火归属层，在入场时固定；跨层模块不会因多层占位重复抽签或叠加防火系数，外挂模块如以后获得点燃来源，也按同一归属层规则处理。这个工程近似需写入界面/技术说明。
3. 用战斗种子、稳定弹丸身份、目标舰/模块身份及效果序号形成独立、可复现的随机样本；不使用帧率、界面刷新、墙钟或不稳定的进程哈希。不能改变现有瞄准/散布随机序列。相同输入失败重试得到相同判定，不额外创建无限事件历史。
4. 同一弹丸对同一模块最多一次尝试。已经燃烧的模块再次受燃烧弹命中时，只有新尝试成功才按 D1 现有强度/时长上限合并，不给已有火情重新抽签；不同弹丸可各自形成一次尝试。
5. 弹丸直接毁伤先结算，合法点燃进入同一步候选；新火情从下一模拟步开始造成持续烧伤，现有同一步损管可处理新火情。最终边界需在实现中固定并验证，不能因迭代顺序多烧一次。点燃、伤害、资源与火情同一步原子提交，失败全部回滚。
6. 暂停、离场或已结束战斗不产生新的尝试。跨场保存已有火势和剩余时间，再入战继续现有规则，不能通过载入重新判定起火或免费灭火。无需完整交战检查点。

## 针对性验收

- 固定样本覆盖概率 0/1、阈值两侧、防火开/关、另一层无加成、同层分离区域、跨层模块单次归属、零净填充体积和多弹重复命中。使用同一组样本对照防火前后结果，避免少量随机射击误判效果。
- 对相同的已存在火情，有无防火填充的逐步烧伤、自然衰减和损管消费完全一致；无火源时防火判定调用数为零，入场后不重扫填充几何或验证设计。
- 真实发射覆盖装甲阻挡、穿甲但未命中模块、有效命中、直接摧毁模块及命中非活动舰；使用有限固定种子证明点燃和未点燃两条路径。
- 真实燃烧弹预装/换装与高能燃料货物消费可对账；库存不足整批拒绝；旧待发弹身份、在途弹种、取消/重试/失败回滚及结算完成有效批次沿用 S1。
- 结算保留船壳/模块/装甲、余弹、货物、损管资源、火情及灵烷余量；重启并再次准备不免费修复、补货或灭火。测试起火损毁原生燃料槽时仍只丢失该槽灵烷，货物不烧毁。

## 后续范围收口

H5d 联合验收后，先处理实际测试发现的编辑、准备与战术操作问题并完成待留档项目，再复盘战略模式所需的舰艇实例、入战输入和战后结果接口；战略模式另立实施计划，不等待全部特殊弹或持续毁伤系统迁移。

近炸弹、制导弹、复杂战术 AI、火灾蔓延及燃料爆炸按明确玩法需求再安排；动态资源质量/惯量按统一资源模型单独评估，不混入防火功能。货物燃烧、逐口径后勤及交战中断点续玩不是默认后续任务。微机修复材料仍由用户另行安排。
