# 导弹在途换层、重力与固定寿命

日期：2026-09-18。状态：下列设计规则已确认；5j.1 固定寿命、5j.2 实际换层/重力/回落/连续碰撞、5j.3 异层数据链与防御协调及 5j.4 联合验收已完成，见[5j.4 记录](./tactical-stage5j4-joint-acceptance.md)。本专题覆盖旧规划中的“导弹终身固定作用层”和“按高度层配置无动力寿命”；5e～5i 的实施记录继续作为旧实现的历史证据。下一工作包为 6，15～30 舰规模终验仍归 7。

## 已确认规则

### 适用范围与发射

- 全部现有制导导弹具备在途换层追踪能力，包括反舰弹与拦截弹；型号差异体现在机动能力、损耗及失锁后的行为。
- 保留现有发射规则：只允许本层或相邻层发射，直接出现在所选层；跨层发射降速并降低发动机可推进的速度上限。上下发射使用相同比例；这项发射抽象不等同于出弹后的实际爬升或下潜。
- 助推段仍固定方向、不能转向。VLS 已出膛转向延迟仍不消耗三段动力与寿命，期间不能改令或退弹；平面出弹时仍使用原定初始层。
- 炮弹仍在发射时固定所属层，不因本次导弹改动获得换层能力。

### 在途追击与重力

- 导弹根据有效目标情报调整爬升或下潜过程；不能通过直接读取未观测的目标真实层级、位置或机动来追击。
- 相邻层机动按约 5 公里垂直距离衔接，逐层完成；需要保存实际垂直位移、速度和姿态，不能只累计固定读条后瞬移。
- 向下换层时重力增加速度，向上换层时重力降低速度；发动机推力与转向损耗另行结算。无动力导弹可以下潜加速并可能增加航程，向上追击会消耗速度，不能保证完成。
- 调整爬降轨迹可以改变加减速的过程；相同爬升高度所需的重力势能不能因更换路径而免除。连续上下往返不得凭空增加能量，转向损耗和耗时不返还。
- 获得有效的新目标情报后，允许途中重新规划，保留实际高度、速度与姿态，并受正常转向能力限制；不要求无条件完成旧目标层后才能改向。
- 尚未自主锁定、但有有效异层数据链指令时，先向指定层飞行；本层无关目标不立即覆盖该指令。到达该层或链路失效后恢复正常自主搜索，首次自主锁定仍须在当前碰撞层内。
- 命中和被拦截共用唯一的所属层：当前相邻段完成前属于原层，完成后切到目标层；不同时命中两层，也不获得换层无敌期。完成一段后，该目标层成为下一段的原层。
- 上爬失败并回落时，未完成的层切换不生效，所属层仍为该段原层。实际垂直位移仍须连续，不能因碰撞所属层未变就清空爬升高度。

### 无动力上爬中止

- 最低上爬速度初值为 **50 米/秒**，允许按型号覆盖。
- 判据使用弹体总飞行速度，不使用垂直分速度或俯视画布上的水平分速度。
- 无动力上爬降至阈值时放弃本次换层，保留已经爬升的实际高度并转入回落，不立即自毁；回落继续计算重力、机动及寿命。
- 机动失败与导引头失锁分开处理：是否仍能锁定继续由有效观测、天气、视锥和干扰决定，不因无法上爬而伪造失锁。
- 上爬失败后先回落至该段原层；该枚导弹在本次飞行中不再向同一目标尝试上爬。按目标身份保留失败记录，重新锁定或数据链再次指定同一目标不能清除记录；这不是把该目标从感知或全部攻击候选中永久删除，目标回到可攻击层时仍按正常条件处理。

### 换层途中失锁

- 直飞型逐步拉平，保留实际高度与最后水平航向，不瞬时回到所属层的高度锚点。
- 记忆型继续朝最后有效观测的目标层与区域飞行，衔接已有记忆/二次搜索能力；不读取目标失锁后的新机动。
- 两类都继续受转向能力、重力、剩余寿命限制；无动力上爬低速中止及回落规则优先执行，不能借拉平或记忆追击绕过。

### 固定无动力寿命

- 每个型号配置一个固定无动力时长，取消上层／云层／雨层分别配置无动力寿命的旧规则；不在发射时按天气选取，也不在换层后按天气重算。
- 总寿命为：`助推时长 + 主发动机工作时长 + 型号固定无动力时长`。从进入平面飞行时起连续计时，VLS 出弹前的既定延迟不计入。
- 进入无动力段后，剩余时长随战斗模拟时间正常扣减；换层、回落、失锁、重捕、重新规划和数据链换靶都不刷新、不加速消耗、不返还寿命。暂停仍沿用模拟时间暂停规则。
- 正常寿命自毁时刻在开始三段飞行时确定；命中、成功拦截及战局结束仍可提前结束弹体。
- 换层通过重力与机动改变速度和可飞距离，不通过改变寿命表现续航差异。云雨继续影响导引头和传感器的既定感知规则。
- 用户已确认首轮固定无动力时长：常规火箭弹 **30 秒**、涡喷弹 **45 秒**、专用拦截弹 **10 秒**，允许各型号独立调整。这次明确采用原上层初值替代旧三层配置，不是读取时静默选择最大值。

## 实施衔接与可调参数

以下保留实施衔接事项和可调参数。运动及控制律见[5j.2 记录](./tactical-stage5j2-layer-maneuver.md)，异层数据链与跨层威胁协调见[5j.3 记录](./tactical-stage5j3-layer-coordination.md)，全目录与四舰联合结果见[5j.4 记录](./tactical-stage5j4-joint-acceptance.md)。这些项目已完成本包接入，不据此新增额外玩法；最终平衡仍可继续调整。

- 各型号爬降角、水平与垂直机动共享过载的控制律、拉平条件及具体参数；重力增速与发动机推进上限分开计算，避免旧限速逻辑抹掉下潜加速。
- 无动力上爬失败后的连续回落轨迹、同一目标不再上爬的状态保留及其他合法目标的衔接；有动力低速状态不直接套用无动力中止规则。
- 按已确认直飞/记忆差异接入失锁中的垂直控制、返层与改选目标，参数与具体转向曲线通过样本调试。
- 30/45/10 秒固定时长及旧三层配置版本迁移已在 5j.1 完成；继续处理初次搜索与数据链候选的层过滤、跨层威胁预测及火力分配、层切换边界的连续碰撞顺序。
- 界面区分当前所属层、目标层、机动进度、总速度、剩余寿命及上爬失败原因；旧三层寿命/射程展示须随新模型调整。
