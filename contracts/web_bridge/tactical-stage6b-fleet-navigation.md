# 6b：舰队命令与撤离机动

2026-09-20。接续 6a SCIC；本轮实现舰队航行和武器命令，正式距离脱离、单舰离场与终局分配接续 6c。

## 已确认与接通的行为

- 旗舰继续独立直控。随伴舰默认保留入战时相对旗舰的舰体坐标偏移，旗舰转向时编队随之旋转。
- 舰况内新增紧凑舰队命令：指定航点、保持位置、归队、攻击火控所选敌舰。点击画布替换路径，Shift 追加，最多 32 个航点；只绘制所选本方舰艇的路径。参数包含目标航速、可选固定航向和期望交战距离。
- 到达最后航点自动归队；攻击目标失联后归队。保持位置持续有效，直到新的航行命令。换层沿用独立命令和读条，航行命令不取消换层。
- 攻击只读取本舰有效观测中的敌舰及其位置、速度和层。普通火炮自动集中攻击；导弹只使用已经开启自动发射的普通发射器，不开启其他发射器。近防炮和自动拦截弹继续独立防御。退出攻击后普通炮恢复自动择敌，导弹保留此前单独配置。
- 敌方旗舰按自身有效观测选择敌舰、接近至初始 3 公里交战距离，随伴舰沿用相对编队；无观测时保持。未接入战略级敌方撤退决策。
- “整队撤离机动”按下令时远离敌旗舰的方向航行，共同目标速度取仍可机动成员中最慢舰艇的可持续前进速度。推进失能成员保留待修，不把共同速度降至零；设备可用性与效率变化会重新估算。舰船依靠真实发动机渐进加减速，不瞬移、不强制改速度。取消撤离恢复随伴舰原有命令，旗舰停车保留惯性；手动操作旗舰车钟或转向也接管并取消整队撤离机动。
- 暂停不推进命令，恢复时操纵复位不取消撤离。实际控制仍经过设备、人员、供电、安全限制和毁伤；不授予随伴舰旗舰直控权限。航行控制每 6 个固定步更新，其他步复用结果。

“结束本场交战”保留测试用途，不能视为正式脱离。6c 仍需实现双方旗舰距离、全体完成换层后更新脱离阈值、单舰脱队撤离、推进待修舰结算、旗舰损失和战略 NPC／残骸交接。

## 转向推力校准

按用户本轮要求，有人和无人化侧挂转向发动机均从 **10,000 N 提高为 100,000 N（10 倍）**。主发动机、质量、耗电、人员和燃料配置不随本次校准改变；实际角加速度仍受力臂、转动惯量、响应时间和安全限制影响。

新增同 ID v3 原型，来源为[转向推力目录](../../舰艇数据/模块/测试夹具/战术转向推力校准目录.v3.json)。保留旧目录和旧存档指纹；新准备政策 v16 显式选择 `maneuver_thrust_revision: 3`，旧栖装导入也升级到新原型，不要求重新放置。目录与能力面板显示 100,000 N。原编辑文件保留历史引用时提示战术准备会升级。

已有战术舰艇在返回准备、读取舰艇库时升级：先备份，再在同一事务替换设计与资源绑定、递增舰艇修订号并更新有效准备草稿。保留各类库存、已装弹、伤员、装甲和模块战损；已提交准备与战果历史不重写，已保存准备关联解除后重新核对。战斗占用或尚有待保存结果的舰艇延后升级，待保存／放弃结果后再处理。重复升级不叠加推力，不再次改库存。

本机旧测试舰两艘仍被战斗占用，本轮没有强行解除其占用。工具 `python -m tools.upgrade_maneuver_preparations` 默认预览，`--apply` 执行空闲舰艇升级；正常准备入口也接入同一流程。
