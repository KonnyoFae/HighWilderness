# 7c.2：航空返航试算与无变化状态复用

日期：2026-10-12。状态：**7c.2 已完成本轮范围，正常速度性能仍未通过，下一片为 7c.3。** 接续 [7c.1b](./tactical-stage7c1b-observation.md) 和 [7c 优化计划](./tactical-stage7c-optimization-plan.md)。本片优化航空计算，自动降速仍归后续 7c.4b。

## 实现范围

- [`aviation_recovery.py`](../../backend/high_wilderness_sidecar/aviation_recovery.py) 新增只读接收资格试算。按接收舰配方计算剩余挂载/机炮弹药卸载体积，加上机体、现有货物和实际需要暂住货舱的机组。人员仍优先使用机库空位，再使用兼容军官舱；已有待命机组、整备预留人员、健康/受伤/死亡状态及原有临时安置人员均计入。非空中状态回退到完整试算。
- 每次候选资格直接读取当前库存，不使用跨调用或资源版本缓存。同一步前一架回收、人员腾出床位、修复机体回到货舱后，下一架立即按新状态判断。候选排序仍为母舰优先、距离及稳定序号；拦阻索、换层、等待、转降、打捞规则保持原样。
- 真正回收仍调用原 `receiving/recover`，执行卸弹、机体与机组转移、源/目标状态验证和提交；轻量判断不转移资产，也不承诺预留容量。卸弹配方提取成共用函数，避免资格判断与实际回收各自维护配方。
- [`aviation_combat.py`](../../backend/high_wilderness_sidecar/aviation_combat.py) 无飞机受击时直接返回输入；[`aviation_flight.py`](../../backend/high_wilderness_sidecar/aviation_flight.py) 无终局/母舰离场时跳过整份复制。有命中或离场仍保留深复制，后续运动和武器阶段、玩家命令也在写入前复制，任务、设备设置、冷却和航迹内的可变成员不通过候选泄漏到已提交状态。
- [`aviation_logistics.py`](../../backend/high_wilderness_sidecar/aviation_logistics.py) 为纯倒计时建立新作业记录及新库存外层，复用只读资源和清单。仍验证航空状态；不改变资源账本和预留。队列、毁伤、坠毁、人员无效/待安置、完成或终局边界继续走完整 `Work`。完成及取消时仍按原规则一次性处理。

未改变模拟步长、观测频率、随机过程、武器/飞机性能、人员规则、前端协议或过载保护。本片不尝试消除运动和武器阶段的全部深复制。
