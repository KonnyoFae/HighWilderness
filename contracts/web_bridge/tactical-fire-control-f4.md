# F4：近防滚动轨迹与撞舰预测共享

2026-09-20。本片完成观测轨迹复用、撞舰结果滚动、保守筛选及事务提交。下一步为 F5 实际页面与后台持续运行联合验收。本片的固定步性能样本不能代替持续运行验收，也不代表最高编制已经通过。

## 实现

旧路径先把同一份观测推进到当前时刻，再用每步略有变化的速度重建未来轨迹；即使没有新观测或本方机动，也会重复计算。现在以观测的原始位置、速度和时间为起点，直接读取该轨迹在“观测年龄＋未来时间”处的位置。继续使用现有 60 Hz 阻力积分，不改变实际飞行或改读敌方未来指令。

- 相同阵营、相同时间戳及相同完整观测样本共用预测；不同来源给出的不同样本保持分离。近防预警、炮弹／导弹拦截分配，以及在途拦截弹搜索所需的撞舰检查接入同一候选步骤；样本相同才允许共享。
- 撞舰结果保存绝对预计接触时刻。没有新样本且本方舰艇沿原速度／角速度运动时，只向前推进倒计时。每次重算后，预计 3 秒内接触的威胁将下次刷新间隔上限设为 3 步，其余为 12 步，并按弹体身份错开相位；新观测或本方变化不受该周期限制。
- 本方速度、角速度、非预期位移／朝向、完成换层、有效舰艇集合、模块生存状态变化立即使旧结果失效。已经过去的接触时刻也不能继续遮挡后续接触。
- 预测窗口保留原来的 30 秒；内部额外预测最多 0.2 秒作为滚动余量，再按当前时刻裁回 30 秒。缓存“窗口内无威胁”时，仍能发现刚进入窗口边缘的目标，不把余量区提前当作可拦截威胁。寿命仍限制全部预测范围。
- 生成完整路径前，先用弹体路径和舰体移动范围的保守包围盒及高度层区间排除不可能相交的组合；包围范围包含舰体半径与旋转近似余量。最终仍检查实际甲板装甲／外露模块的扫掠接触，不以圆形接近代替碰撞。
- 每步仍检查有效观测来源、敌我、存活、拦截资格与当前库存。失联或目标消失不会因缓存而继续授予拦截权限；高度运动只采用已观测的高度和垂直速度。本方未完成的换层指令不被当作已经换层。
- 在途火力分配继续按现有规则逐步检查共享条件、弹体状态、寿命和可达性，未把“已分配伤害”写入预测耐久。失去数据链、拦截弹转向新目标或无法继续上爬等既有释放规则仍生效。

预测状态在战斗步骤成功后提交；失败步骤保留原状态与指标。只保存本步实际使用的条目，失联／不再需要的条目随提交清理；纯轨迹缓存仍受原有 256 项上限约束。新增内部 `prediction_metrics` 记录请求、重算、同一步共享、跨步滚动、运动失效、粗筛、路径数量及最大解龄，不进入战果或前端存档。

本片没有改变近防炮的精确拦截射击解、射速、伤害、传感器额度、导弹制导频率或过载阈值。普通炮继续使用 F3 调度。实际碰撞和剩余寿命仍具有最终决定权。

## 对照与验证

[对照工具](../../tools/profile_tactical_defense_prediction.py)复用 [F1/F2 冻结输入](../../artifacts/tactical-fire-control-f1f2-20260920/fixture.json)，比较相同 F3 普通炮路径下的旧近防预测与 F4。每组执行 240 步、每四步发布和读取一次视图；完整步统计去掉前 30 步，近防统计包含全部步骤。另加入一门实际 30 毫米近防炮对 12 枚 900 m/s 来袭弹的 180 步齐射样本，真实执行拦截、损伤和资源消耗。所有样本使用隔离数据，不修改用户测试缓存。

冻结场景的逐步发射记录、库存、威胁身份均与对照一致，没有漏报或新增威胁；预测到达时间的差异小于 0.1 毫秒。密集齐射也逐步比较实际开火、命中、舰体受击与库存；对照仅排除测试夹具自动生成的舰船实例标识，不排除任何资源字段。性能明细、环境与源码摘要见[结果](../../artifacts/tactical-fire-control-f4-20260920/result.json)。

| 场景 | 完整步均值，旧 → F4 | 近防预测均值，旧 → F4 | F4 完整步 P95 |
| --- | ---: | ---: | ---: |
| 12 km，静止炮战 | 14.24 → 4.16 ms | 10.97 → 2.07 ms | 15.66 ms |
| 16 km，100 m/s，原库存 | 9.14 → 3.14 ms | 6.35 → 1.26 ms | 12.64 ms |
| 16 km，持续推进 | 9.97 → 3.37 ms | 7.03 → 1.41 ms | 13.14 ms |
| 16 km，已装满待发弹 | 9.08 → 3.22 ms | 6.24 → 1.25 ms | 12.57 ms |
| 16 km，空弹 | 1.45 → 1.53 ms | 0.01 → 0.01 ms | 1.96 ms |

16 km 移动原库存样本的完整撞舰预测由 540 次降到 130 次，其余 410 次滚动复用，最大复用年龄为 5 步。密集齐射的完整步均值为 5.41 → 2.98 ms，预测由 1008 次降到 446 次；两种路径均发射 56 发近防炮弹，产生 36 次实际耐久命中、摧毁 12 枚来袭弹。全部逐步事件相同。以上是单机短时受控计时，包含测量开销。

本轮仍可出现超过 16.67 毫秒的单步峰值；新观测集中到达仍可能集中刷新。短时均值下降不等于长期运行不会过载，留待 F5 检查实时调度、发布读取与前端开销。

- 未更新的观测不读取敌方新的真实运动；新样本、失联与目标消失当步生效。

- 友舰等值观测共享；接收舰失去来源后立即失去拦截资格，其他有效观测舰可继续处理。
