# U2b：分类图标、密集标记与观测展示

后续更新：同日 [U3 联合验收](./tactical-ui-u3-joint-acceptance.md)已完成，UI 工作包 U 完成本轮范围；下文保留 U2b 交付时的范围与接续记录。

日期：2026-09-20。状态：本片已接入并通过范围内验证。下一阶段为 U3 联合验收，随后是 F 火控优化，再进入工作包 6 的 SCIC／舰队指挥；本片不代表整包 UI 重构已交付。

## 图标与保存

- 舾装编辑器提供圆点、菱形、三角、方形、十字、星形六种分类图标。只改变显示，不改变质量或其他性能。
- `outfit.set_classification_icon` 接收 `{icon}`，走原编辑会话、修订、撤销／重做和保存流程；存在未提交的模块或武器组表单时禁止并发修改。文件重开、便携舾装、战前设计归档、战斗几何及结算后准备复用该字段。
- 显式设置图标后采用 `gaotian.outfit-plan/v3alpha1`，保留 v2 的全部分组规则，并增加必填 `classification_icon`，取值为 `circle/diamond/triangle/square/cross/star`。未知值拒绝。武器组和模块编辑不能丢弃图标或降级格式。
- 旧 v1／v2 舾装只在显示时回退圆点，不注入新字段，不改变其规范输出和资源指纹。首次设图标时将默认武器组明确保存；资源自身的版本号仍遵循既有另存规则。
- 准备画布、战斗舰队列表及本方舰艇标记使用同一图标；旗舰仍由 `01`、颜色及“旗舰”标签识别，不增加“选旗舰”按钮。敌方标记使用默认圆点。

## 密集与异层标记

- 重叠图标按稳定顺序避让，优先保留选中项的位置；错位的场内图标用细线指回实际舰位。选中条目、连接线和图标继续联动。
- 视野外图标沿画布边缘排列，箭头保持真实舰位方向；同方向多舰可以分散到相邻边缘，不移动或缩放镜头来容纳它们。
- 本方舰艇与有效观测的敌舰在异层仍显示带层级标签的标记，本层才绘制舰体；双击图标只切换观察层，不向舰艇下换层命令。
- 舰队列表的首次双击平移、再次双击同一已聚焦项才适配细节；打开面板、切换子页仍不改变画布矩形和镜头。

## 观测边界与物理效果

- 正式战斗画面以当前操作舰实际可用的观测为准，包括有效数据链共享；不合并没有共享条件的所有友舰情报。当前本方舰艇状态仍可查看。
- 敌舰位置、速度、高度层、朝向和角速度来自观测样本；不读取实时敌舰耐久、库存、人员、下坠读条或残骸状态。已知设计几何继续支持模块瞄准，本片不是网络数据保密实现。
- 全部来源中断后立即移除敌舰实形及可点选对象，插值缓冲中尚存的旧实形也移除；仅用虚线圆保留最后观测位置。失联标记不接受目标分配，记忆到期后消失。火控列表仍可聚焦最后观测位置，不替换本方操作舰。
- 敌方导弹及具有耐久的大型炮弹仅按有效弹体观测显示；不携带未获知的实时轨迹和发动机状态。
- **用户已确认：没有耐久、无法自动锁定的小口径敌弹，以及敌方箔条云和热能烟雾，保留物理效果；目标标记与火控资格仍受观测限制。** 小口径弹的短命弹迹也由结束飞行历史保留，避免一发弹在两次快照之间结束就完全不可见；不为它们补建火控目标。主动诱饵不属于这次额外放开的云区显示范围。
- 命中与拦截记录限制为本方相关结果，不显示全场累计毁伤数字；本方射击瞄准线在目标失联后隐藏。现有自动射击、导引、碰撞及观测额度规则不变，后台继续校验每条命令。

## 验证与接续

- 前端类型检查、40 个文件共 170 项测试及生产构建通过。含 18 个重叠／同向视野外标记、观测过滤、立即失联、物理弹迹与云区、观测敌舰炮组目标选择；18 个标记测试不等于 9 对 9 战斗性能验收。
- 本轮后台共 72 项不同用例通过：图标编辑与持久化、v1／v2 往返、武器组、准备与入战、观测、实时视图、弹迹和电子对抗。回归另修正了关闭毁伤的旧实验场景中，电子对抗从可空毁伤对象读取阵营导致暂停的问题；阵营改取已有场景归属，不改变战斗规则。
- 隔离 Python 后台连接真实 React 页面，通过图标编辑／撤销／重做／保存／重开，准备到战斗复用、混层重叠标记、未发现敌舰隐藏、本地感知失效后友舰共享接替、完全失联与记忆到期、全队结算保存返回准备。已保存准备与后续编辑的设计是独立版本，不隐式替换存档。
- 1920×1080、1366×768 检查面板开合前后画布矩形、镜头及标记位置不变。证据：[U2b 结果](../../artifacts/tactical-ui-u2b-1789875163608/result.json)、[1366 窗口](../../artifacts/tactical-ui-u2b-1789875163608/workspace-1366.png)、[失联显示](../../artifacts/tactical-ui-u2b-1789875163608/lost-contact.png)、[编辑图标](../../artifacts/tactical-ui-u2b-1789875163608/editor-icon.png)。脚本为 `tools/verify_tactical_ui_u2b.mjs`。
- [U2a 回归](../../artifacts/tactical-ui-u2a-1789875030427/result.json)亦通过，涵盖旗舰即时操纵、真实角速度回正、换层独立、各舰页面记忆和单场结算。双击缩放验证先主动缩远，避免依赖开场能够看见未知敌舰的旧全知镜头前提。
