# O3b：舾装画布最小范围

2026-09-07。用户船壳与资源包舾装均接入画布；O3c 武器组与 O4 完整三舰验收另行推进。

## 操作

- 原型目录 → 放置所选原型 → 点击画布；自动生成不重复实例 ID。
- 点选、拖动移动、允许朝向内旋转、移除；R / Delete / Esc，复用历史和恢复机制。
- 内部/顶挂采用符合模块格心奇偶性的强制网格锚点。锚点均为 2.5 m 整数倍；实际占用必须落在 5 m 安装格心。没有关闭吸附选项。
- 侧挂点选实际船边槽位，保存精确区域/边/槽身份。嵌入通过可用宿主列表或点击宿主操作，排除不匹配版本、缺槽和已占用槽。
- 甲板切换、下层半透明参考、缩放和平移。跨层模块在其占用甲板可选；拖动保持原基底甲板，通过“点选新位置”再切层可明确迁移。
- 内部、顶挂、侧挂、本体、净空图层可切换。冲突模块标红、错误列表可选择；重叠时优先选中当前所选模块，避免无法拖开。

精确位置表单收纳在折叠详情中，画布优先显示。武器组与高级批量/镜像尚未接入。

## 权威布局与非法草稿

Sidecar 舾装预览的 `model.layout` 新增带独立版本的 `gaotian.outfit-layout/v1alpha1`，包含 `hull`、`decks`、`modules`、`errors`、`conflicts`。无此版本的旧后台明确提示更新，不允许画布提交。

新公共辅助 `preview_outfit_layout` 调用既有舾装编译器的实例放置过程；内部、顶挂、侧挂和嵌入几何没有第二套后台算法。保留可解析实例，逐个报告放置错误，并按实际占用/本体/净空键报告冲突双方。独立船壳几何与安装格不依赖整舰合法性，因此空白、缺少 CIC/升力、局部越界或重叠时仍能编辑。

布局不是合法整舰派生结果。原 `preview.valid` 与保存门槛不变；错误实例不伪造权威几何。前端对不能编译的网格实例仅按源锚点/外形画红色草稿参考。悬停外形及越界、格子重叠提示属于本地预览，完整跨层、侧挂、宿主、净空及整舰条件由提交后的后台检查。

原领域 `preview()` 默认输出不变，历史黄金报告不重设；仅 Sidecar 显式加入布局，撤销、重做、保存重开和恢复每次从当前草稿重算，不能拿最近合法布局代替当前非法草稿。
