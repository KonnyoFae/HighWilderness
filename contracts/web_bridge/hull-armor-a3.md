## 防护结算

- 沿用原结构轮廓的二维扫掠接触及概率甲板选择，装甲外飘投影不增加碰撞甲板或额外命中次数。命中仍绑定原 `deck_id / deck_level / region_id / edge_index`。
- 开战时读取A1/A2预编译的逐边余弦。只执行一次 `α′ = acos(clamp(cos(α) × cos(θ), 0, 1))`，然后进入既有归正、斜面指数、跳弹、穿透和剩余能量公式。真实板厚不变，不再叠加一次等效厚度。
- 炮弹和导弹均接通；导弹继续使用含垂直分量的相对总速度计算穿透，原入射角也保留垂直分量，再应用同一倾角近似。不新增俯冲抵消斜面的精确三维模型，也不改变水平后效射线范围。
- 独立弹丸世界与当前战术毁伤内核共用倾角函数，避免两条路径产生不同防护口径。未开启外飘时直接返回原角度，旧版和v4零倾角结算保持一致。
- 局部耐久沿用A2实际板材体积上限；受击只扣中弹边。耐久归零时穿透阻力为零，但设计厚度、外形、安装禁区、射界遮挡和质量仍保留。装甲受损不重编译几何。
- 外飘命中事件附带真实厚度、倾角、归正前后角度、需求/可用穿深及防护是否有效，供回归与诊断使用；旧舰事件不增加该字段。
