# W2a 编辑会话合同

实现入口：`backend/high_wilderness_sidecar/sessions.py`。桥接信封继续为
`gaotian.web-bridge/v1alpha1`，业务结果使用独立接口，不改变旧资源或黄金。

## 能力与请求

| 方法 | 会话与修订 | params | 结果 |
| --- | --- | --- | --- |
| resource.list | 均为 null | `{}` | `gaotian.editor-resource-index/v1alpha1` |
| editor.open | 均为 null | `{resource_key}` | 新 `gaotian.editor-session/v1alpha1` 快照；新会话身份在 result 中，响应信封仍无会话 |
| editor.inspect | 已有会话，提供本地已知修订 | `{}` | 当前快照；允许已知修订过期，用于冲突后刷新 |
| editor.preview | 已有会话，精确修订 | `{}` | 对应修订的已计算权威预览，不重复编译、不增加修订 |
| editor.command | 已有会话，精确修订 | `{command, arguments}` | 修改后快照 |
| editor.undo / editor.redo | 已有会话，精确修订 | `{}` | 历史内容的新修订快照 |
| editor.close | 已有会话，精确修订 | `{discard_changes: boolean}` | `{closed: true, session_id}` |

首版命令仅有 `hull.rename`（arguments 为 `{name}`）与
`hull.set_structure_material`（`{deck_id, material: {id, version}}`）。多余字段、
非法类型、空名称、未知命令及不存在的甲板均拒绝，不修改草稿或历史。
名称上限 256 字符。材料引用格式合法但资源不存在时，保留非法设计草稿及诊断。

## 资源与所有权

目录为显式开发资源包：三条阶段 F 船壳、三条舾装、三个模块目录、两个材料目录、
一个涂料目录。逐项解析并计算规范指纹；不从报告目录收集资源，不接受前端路径。
每项给出 `key/kind/id/version/name/sha256/editable/read_only/usage`。
`read_only` 指源包不可写，`editable` 指可创建内存编辑副本，目前只开放船壳。
索引在后台实例内固定，后台重启重新验证；持久化前的磁盘冲突检查留给 W2b。

会话由单个领域工作线程拥有，最多 8 个会话，每个会话撤销与重做各至多 64 份
历史草稿。源资源、对外快照和修改候选均分离；修改在候选上预览后唯一提交。
成功改变内容的命令、撤销和重做增加一次修订；同值命令、读取、失败均不增加。
新命令清空重做栈。`dirty` 比较当前草稿与打开时源资源的规范指纹，撤销回源即清除。

会话快照包含接口、后台实例、会话 id、修订、资源描述、草稿、草稿指纹、脏状态、
撤销/重做可用性、历史上限、当前预览、最近合法预览与其修订。
预览沿用领域层 `EditorPreview.to_dict()`，保留结构化 code/path/message。
非法草稿不覆盖最近合法预览；撤销可恢复合法内容。持久保存与草稿落盘未开放。

## 通信与失效

读取入口先验证严格递增请求号，再把编辑任务放入容量 8 的队列；独立线程处理
输出（容量 16），系统 ping 不等待领域编译。单帧仍为 8 MiB。
队列满返回 `bridge.busy`，该请求未执行；已接收的编辑任务按接收顺序串行执行。
正常 EOF 或 shutdown 排空已接收任务，宿主原有关闭期限与强制回收机制仍有效。

宿主白名单只透传上述八种能力。调用绑定后台实例和成对的会话/修订，过期后台
在发送前拒绝。请求编号与入队使用同一锁，避免 UI 与心跳并发打乱请求顺序。
响应信封须属于原请求的会话。普通领域错误不会把宿主改为 FAILED；超时仍按
原合同标记结果未知并终止该后台实例，不能自动重放变更。

前端按后台实例重建面板，并依据本地请求票号、会话 id 与修订过滤返回结果。
旧请求完成、旧后台、其他会话和低于当前修订的预览均不得覆盖当前草稿。
发生修订冲突后可调用 inspect 获取新修订，再由用户重新决定操作。
