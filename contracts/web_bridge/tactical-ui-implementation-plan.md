# 战术 UI 重构优先实施计划

2026-09-20 排期补充：用户确认火控与近防优化方向，安排在本工作包 U 完成后、工作包 6 之前；当前继续 U2。见[火控优化 F](./tactical-fire-control-optimization-plan.md)。

日期：2026-09-20。状态：U1 与 U2a 已接入并通过范围内验证，见[U1 记录](./tactical-ui-u1-foundation.md)、[U2a 记录](./tactical-ui-u2a-controls-and-panels.md)。下一阶段为 U2b，随后 U3；整包尚未完成。本文将 UI 重构列为工作包 U，插在已完成的 5j 与工作包 6 之间；不再等待工作包 7 才整理界面。

## 已确认的实施基线

- 战场画布始终铺满战斗区域，面板以半透明覆盖方式附着屏幕边缘；开合、切页不得改变画布矩形、镜头或静止舰艇屏幕位置。小型图标标签负责折叠。
- 左侧舰队列表负责本方选舰。第一项为有专属标记的旗舰，无额外“选旗舰”按钮。舰艇上方分类图标、列表项与半透明连接线同步高亮；视野外有方向图标。
- 舰队项首次双击仅平移，聚焦后再次双击才适配舰体细节；普通单击不移动镜头。火控目标双击按示意只平移到有效／最后观测位置，保持正在操作的我方舰艇。
- 舰务大面板包含舰况、损管、货舱；首轮采用示意的左下位置。右侧火控大面板持续显示目标列表，下方切换火炮、导弹；感知设备、电子对抗合并为火控中的折叠区，消除原两页重复的完整干扰操作。
- 两块大面板可同时展开，并各自按舰艇恢复上次子页。首轮页面记忆限当前战局；开合状态属于当前布局，不发出任何战斗命令。
- 旗舰操纵采用即时车钟：档位垂直排列并高亮当前档位；左右转向分列车钟两侧，各有半速／全速 toggle。再点当前转向档位，自动用反向推力消除角速度；不回到此前航向。车钟变更保留转向，换层独立。操纵区可折叠，未悬停／聚焦时半透明，查看友舰时仍只直控旗舰。
- 互动示意采用样例数据；其中射程、库存、损伤、火控速度和简化开火反馈不构成新的战斗数值或规则。

完整设计依据见[画布 UI 规划](./tactical-canvas-ui-redesign.md)。不重新讨论已确认框架；尚未明确的细节仅约束所属分片。

## 实施时需处理的细节

- 舰级火控目标与炮组／单武器已指定目标的关系：优先复用当前命令，不能因查看列表就向所有武器或全舰队发令；真实火控锁定条件继续生效。更广泛的目标继承策略在 U2 明确。
- 火炮当前命令权限仍限旗舰；界面必须标明实际可用能力。普通友舰炮组命令的扩大随工作包 6 接入，不能仅靠面板选舰假装已实现。
- 旗舰操纵具体动作已确认并于 U2a 接入；手动瞄准／选点与普通选舰分开，Escape、切舰／切武器页／关闭火控均退出显式输入，不隐式发射。保留测试所需的全部操作能力。
- 目标位置只取有效观测；失联只保留最后观测。观察层、舰艇换层、弹药作用层和舰内甲板各自独立。
- 舰务先汇总实际已有库存；不捏造统一货舱持久化字段，不向战斗搬入战前无限供给、补满或维修规则。
- 顶边与测试菜单保留开始／暂停、结束测试、保存结果及强制放弃；结算占独立阶段，不能被折叠面板锁死。
