2026-09-15 已定主动换层规则按以下公式接入：入战总升力 `L0`、干重 `m_dry`，`a0 = (L0 - m_dry*g_ref)/m_dry`，按相同幅值加速、减速求 `T0 = 2*sqrt(5000/a0)`，首版主动升降沿用同一计时模型。干重不计挂载、货物，战中不随质量变化重算；损失比例 `d = clamp(1 - L_current/L0, 0, 1)`，当前完整一段耗时为 `T0*(1+d)`，损失 25% 即耗时增加 25%。debuff 变化保留已完成进度、调整后续读条速度；紧急抢修可恢复升力并更新 debuff。

同包接通升力冗余、强制下坠和已毁升力储罐紧急抢修：负冗余触发下坠、零冗余不新触发，缺口越大计时越短；逐层下坠，雨层保留末段抢修机会，恢复正冗余立即停止并保持实际层，末段仍未恢复才坠毁。储罐保留未毁满升力，紧急抢修是已毁模块不可维修规则的专项例外。具体计时及抢修完成条件已按专题明确并接入，不提前锁死下坠舰的维修、指挥资格或战局结果。

换层与其他指令并行。取消就是更改换层指令，立即停止旧读条、不改变当前实际层；新目标从当前层逐层执行，已完成的前一段不回退。各舰实际层、观察层和舰队脱离阈值依据分别处理。更新现行层状态校验和快照，不逐步模拟真实垂直速度，不加入舰艇互撞。

验收既看运动是否连续，也看输入反馈、层切换边界与暂停是否正确。换层重点覆盖干重与基准升力预计算、货物变化不影响耗时、升力损失 25% 的倍率、半途受损读条连续、取消保持当前层、第二段取消保留云层，以及移动/攻击与换层并行。素材接口可用可替换的临时素材验证，最终美术精修不阻塞战斗规则接入。

升力生存流程另以两条场景联合验收：实际储罐损毁→冗余转负→逐层下坠→消费真实资源抢修→正冗余恢复且停止读条；以及抢修未成功→雨层末段完成→最终坠毁并只生成一次结果。零冗余不新触发、缺口越大下坠越快、不可通过取消指令逃避下坠、下坠期间不提前终止旗舰控制或战斗均须覆盖。具体数值与零点边界按专题的最终决定验证。

2026-09-20 已确认：普通 CIC 舰艇可以独立单舰行动和作战；两艘及以上共同行动或联合入战时，至少一艘须具备 SCIC，并由具备 SCIC 的舰艇担任旗舰。普通 CIC 舰可作为随伴舰，无需全员安装 SCIC；多舰仍需满足随伴容量，敌我采用同一规则。准备、部署、保存及恢复须区分单舰与多舰资格，不得将 SCIC 设为单舰入战的必要条件。SCIC 单舰、普通 CIC 单舰、无 SCIC 双舰与 SCIC 旗舰带普通 CIC 随伴舰均纳入本包验证；本条明确编成与入战资格，战中失效仍按本包终局规则细化。

基础舰队选择与命令入口可以从工作包 1 持续建设，本包完成联合行为：移动与多段路径、朝向/速度/高度指令、相对编队、攻击和交战距离、归队、实际武器使用及必要的敌方指挥行为。

完成整队统一速度撤离、双方旗舰测距，以及被动应战舰队的有效脱离阈值：只有仍参加整队撤离的舰艇全部到达目标层才更新，排除残骸和指定单独撤离舰。既有程序的立即 `withdraw` 不能再充当正式撤退过程。

统一处理原地残骸与待修状态：CIC/SCIC 损毁立即坠毁、升力不足先逐层下坠并可抢修且最终坠毁才留骸，既有船壳崩溃仍生效；仅推进失效先待修，最终结算仍未恢复且其余舰艇全部撤退才转为残骸。提供指定单舰临时脱队撤离的命令和独立结果，预留战略 NPC 交接。实际打捞与 NPC 运行不在本包实现。

本包前明确共同速度/调速条件、单舰离场判据、战斗结束时刻与已发生命中的提交顺序和首版旗舰损失结算细节。延续原子保存、真实战损与余量、不重复扣费和待保存结果恢复；调整当前 16 舰上限及相关校验，以支持代表性舰队场景，不能只去掉一处数量检查就宣布规模完成。 已发射在途弹及 VLS 转向中弹视为已使用、不可取回或退料的规则已定，本包负责核对结束保存时不重复扣除，不再将是否返还列为待定。
