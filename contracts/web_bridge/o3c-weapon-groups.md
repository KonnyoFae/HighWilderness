## 资源与兼容

- 旧 `gaotian.ship/v1alpha1` 舾装不增加字段；查看默认分组、移动或增删模块不会升级格式，旧规范输出保持不变。
- 首次提交 `outfit.set_weapon_groups` 时使用 `gaotian.outfit-plan/v2alpha1`，增加必填 `weapon_groups`。每组保存 `id/name/prototype/weapon_instance_ids`；原型引用必须含精确版本。资源自身的 `version` 仍只在显式另存新版本时增加。
- v2 每件已安装武器必须且仅属于一个组，禁止空组、重复成员、缺失或非武器成员、跨型号/版本混组。最多 64 组，名称 1–80 字符。组与成员规范排序。
- v1 按精确原型默认成组，ID 由原型身份确定生成。默认视图不写入草稿，也不改变指纹。
- 新读写端支持 v1/v2；旧读写端应明确拒绝 v2，不能删除分组后降级保存。便携舾装文档继续内嵌规范舾装及固定船壳快照，不引入外部路径。

## 命令与历史

`outfit.set_weapon_groups` 参数仅为 `{groups: [...]}`。候选完整校验成功才替换会话，复用修订冲突、撤销、重做、保存与草稿恢复机制。非法安装草稿可以配置组，但仍不可保存为合法整舰。

显式分组后，通过编辑器增添武器时加入精确原型匹配、ID 排序最前的现有组；无匹配组时新建默认组。移除武器时同步移除成员并清除空组。整个模块命令连同分组更新属于一次修订。恢复时校验当前、撤销、重做及最近合法来源中的全部组引用，完整性指纹相符不代替语义检查。

前端提供组选择、改名、勾选部分成员拆组、同型号组的合并和成员画布定位。局部分组修改须应用或取消，避免与位置表单、画布命令及保存并发覆盖。

## 射界与开火边界

独立预览 `gaotian.weapon-control-view/v1alpha1` 提供有效分组及每件武器的安装原点、层级、状态：

| 状态 | 显示 |
| --- | --- |
| 无更高甲板且安装无冲突 | 360° 船壳参考方向圈；不表示射程 |
| 存在更高甲板 | 明确提示遮挡尚需检查；不绘制全向圈 |
| 安装失败或占用/净空冲突 | 射界暂不可用；不绘制方向圈 |

这复用已有保守射界策略，不假定武器整体可开火。`resolve_weapon_group` 只解析设计组成员，后续战术适配仍须逐件进入既有冷却、弹药、火控及射击队列规则；本切片不自动派发齐射。
