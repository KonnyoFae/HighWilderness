# E1a：独立飞行会话与静态资源编译

日期：2026-09-08。状态：`E1a_IMPLEMENTED / E1_IN_PROGRESS / REALTIME_NOT_PASSED`。

这次实现了实际执行模拟的新会话入口，不再只是测量旧框架。它与桌面 `TacticalService` 分开持有世界、待执行输入和缓存，严格编译只读资源并复用验证结果；计算规则和统一场景的阶段编排仍共享现有代码。它是新路线第一切片，不是已经完成全部类型化内核迁移。

## 已实现的边界

- `backend/high_wilderness_sidecar/realtime_flight.py`：`CompiledFlightResources` 保存静态资源与会话 epoch；`FlightWorld` 保存已提交状态、修订和输入序号；`RealtimeFlightSession` 提供接受输入、固定步推进与显式观察导出。当前只创建既有两舰飞行样例。
- 资源图逐层检查，仅接受不可变基础值、元组和字段同样不可变的 frozen dataclass。材质注册表转换为只读条目；资源描述导出新字典，外部修改导出值不影响资源。证明只针对正常程序写入，不宣称防御任意恶意 Python 反射。
- 静态推进上下文在资源边界严格验证，再以确切不可变对象身份复用证明。统一场景接已有 `trusted_prevalidated` 绑定路径；没有通过编译器的上下文不会获得此证明。
- 响应能力在创建时按原 Decimal/ceil 规则编译，当前样例合并为两种能力；时间内核和受控时间边界都查询编译结果。未编译能力在会话作用域内拒绝，要求资源重建；作用域退出恢复旧严格解析。当前已编译精确时间参数，全阶段偏移表进一步预计算仍可后续评估。
- 只允许同一所有者线程推进，拒绝重入、跨会话/过期/重复输入。输入严格解析后成为不可变准备对象，原始字典的后续修改不会影响它。
- 候选状态与投影成功后一起发布；异常保持旧世界、清除待执行对象并丢弃可能接触过候选的运行缓存。没有静默输入重试。

旧默认入口仍严格校验。新增能力只在实验会话进入受限作用域时生效，不是全局关闭验证或测试 monkeypatch。默认桌面尚未选择此后端；此阶段也没有墙钟调度器。

## 与旧计算规则的关系

仍调用同一套指挥仲裁、完整软硬安全、互锁、响应阶段、配平、运动及场景阶段函数。`FlightWorld.scene` 暂时持有旧类型化场景记录作为兼容状态，尚未改成最终紧凑分域布局；runtime 派生仍使用旧缓存的精确状态依赖。当前不会把设备可用推力永久缓存为出航时数值，但完整“按变化更新”的新依赖图尚未实现和验收。

本片消除了静态重复验证和解析，尚未消除动态状态 `to_dict/parse`、自生成结果的重放验证、大量规范 SHA 和完整诊断构造。这些是 E1 后续切片的工作，不能把 E1a 视为 E1 全部通过。

## 验证与性能

证据：[e1a-20260908-flight-r2/result.json](../../artifacts/t3a-realtime-experiment/e1a-20260908-flight-r2/result.json)。包含源码/资源归档、逐文件身份、对照结果、原始计时及独立机制计数。首轮目录 `e1a-20260908-flight` 保留为 FAIL：发现时间边界仍有直接解析入口，修复后完整复跑，未覆盖旧失败证据。

新旧两条路径分别与冻结 E0 对照，两组 192 步、194 个初始/结果边界均精确一致：完整场景、指挥、仲裁、单步结果、有序事件和兼容回执。实验工具中的有限试航回执形状是对照适配，不是已实现的新实时通信协议。试航样例仍不消耗推进燃料。

三次交替短测，每次 12 步预热 + 60 步测量，两路径都保留主要兼容表现投影工作，输入接受、对照和 I/O 在计时外。旧 worker 与新 session 的少量调度封装不同，因此结果表示两个实际执行路径的差异，不把全部收益归因于单个函数。

| 路径 | 三次平均耗时 ms/步 | 平均耗时中位数 |
| --- | --- | --- |
| 当前旧 worker | 46.043 / 45.403 / 44.894 | 45.403 ms |
| 新独立飞行会话 | 24.246 / 24.119 / 23.796 | 24.119 ms |

本机短测计算时间减少约 **46.9%**，吞吐约为旧路径 **1.88 倍**；仍超过 16.67 ms/步，不满足 60 Hz。计数实验中静态设计指纹重算和精确响应解析均为 **0 次/步**；规范 SHA 仍有 **326 次/步**，完整安全状态验证仍有 **16 次/步**。计数时的 cProfile 耗时不混入性能表。

验证结果：

- 新会话/基线工具与当前 Web T3a 合计 24 项 unittest 通过，覆盖只读资源、输入隔离、跨会话拒绝、失败回滚、作用域恢复及当前功能。
- 额外调用既有功能检查：d1 时间合同/启动/中途改令、d2a 资源迁移和 d3a 受控时间边界共 5 组通过。
- 另 6 组历史功能检查在“conventional_crewed 保存的完好实例不再等于规范输入初始化结果”处失败，与此前历史实例阻塞相同；记录在 `targeted-regression.json`。未更新黄金或历史报告，不宣称旧全量门禁通过。
- 未进行战损注入矩阵、实际交火、存档重载、长跑、UI 切换或规模验收；这些仍由 E2—E5 覆盖。
