# 舰船编辑器界面改造

日期：2026-09-13。状态：界面改造已实现并完成范围内操作验证；用户实际使用体验待确认。

## 本轮要求与实现

- 船壳和舾装画布共用网格分级：半格 2.5 m、单格 5 m、五格 25 m、十格 50 m。颜色、透明度和线宽分级；橙色 X 轴、蓝色 Y 轴、原点圆标、米制刻度与回到原点按钮同时提供。远景简化仍对齐真实坐标，不改变安装格或吸附规则。
- 舾装部件目录固定在左侧半透明面板。类别分页、型号卡片纵向滚动，显示安装方式、质量和额定功率；支持键盘切页。添加 / 拖动切换位于目录旁，模式高亮并提供当前操作说明。
- 添加、拖动模式持续保持；提交、删除、撤销、刷新及 Esc 均不将用户选择重置为默认模式。Esc 取消当前动作。船壳绘制在提交一个区域后仍保持绘制模式，空绘制模式不视为未提交草稿；真正未提交的绘图点仍阻止保存和切换。
- 船壳工具也固定在左侧；画布占据中央，右侧属性独立滚动。舾装精确坐标与武器组收纳到左下角可展开面板。已装模块默认只显示所选名称，完整名称图层可手动打开。
- 操作结果、错误和画布操作提示集中到底部固定高度窗口。鼠标提示、检查结果和处理状态变化不改变画布尺寸；恢复草稿与保存行为保留。
- 舰船数据固定在右上角半透明列表。发电量旁显示全开耗电缺口和功率提示，其余检查问题堆叠在列表下方，以红字缓慢闪烁。系统设置减少动态效果时使用常亮红字。数据区内容超出高度时局部滚动。
- 无合法派生结果时明确标注质量和升力来自最近合法修订；功率由当前已装模块合计，缺失模块信息时不伪装为零耗电。没有修改后台规则、资源成本或安装约束。
- 后台连接详情和事件日志收纳为折叠诊断区。窗口默认 1280×860，最小 1100×720，标题改为舰艇工作台。
