# 7c.0 / 7c.1a：扩展对照与区域遮挡优化

日期：2026-10-10。状态：**7c.0 与 7c.1a 完成本轮范围，实时性能目标仍未通过。** 接续 [7c 计划](./tactical-stage7c-optimization-plan.md)。本片只改共用遮挡函数；观测公共输入、返航试算、航空复制、近防余项及发布读取仍按后续分片推进。

## 实现

生产改动集中在 [`missile_guidance.py`](../../backend/high_wilderness_sidecar/missile_guidance.py)：

- 在几何求交前排除非端点层、未知类型、友方电子区及活动干扰源的反辐射例外。实体箔条和热烟依旧对双方生效，普通雷达辐射源没有新增豁免。
- 遮挡结果按通道取并集：一个通道已经确定被遮挡后，后续同通道区域不再求交；两个通道均已确定时结束扫描。不存在跨调用缓存，因此区域移动、新云释放、换层和设备变化都仍按本次实际输入判断。
- 将通用生成器的线段相交计算改成直接二维运算，保留投影、端点截断、平方距离以及相切算相交的规则。没有改动观测采样间隔、模拟步频、武器参数或过载边界。

本片暂不加入包围框粗筛。先验证上述不依赖粗筛容差的改动；若后续剩余热点仍值得处理，再单独评估粗筛及边界误差。7c.1b 的阶段内观测公共输入复用也尚未开始。

## 扩展状态对照

[`tactical_7c_oracle.py`](../../tools/tactical_7c_oracle.py) 记录 18 类状态：世界/设备/资源/指挥与步骤事件、炮状态和随机种子、火控工作状态、完整弹体及制导状态、观测、库存、导弹、飞机、电子战、近防、毁伤、火灾、人员、弹药爆炸、航行命令、换层命令、撤离和终局。部分相关内容按同一分类合并。

与 7b 摘要相比，新增了观测样本时间/来源/容量、制导记忆/重搜/换层、威胁及拦截状态、航空机组/挂载/任务/回收、库存预留/物资台账、事件和已保存的随机状态。运行时新生成的战场/库存 epoch 作一致替换，持久舰艇、飞机、飞行员及弹体身份不替换。计时器、派生缓存及诊断计数不作为逐字等价的战斗状态；失败步另检查缓存不泄漏。

工具在独立临时战局中逐步运行旧/新实现，比较脱离原对象的完整状态树；有差异时保存首个不同步骤、字段路径和两份状态。成功时只留每类状态的逐步哈希，避免保存大量重复数据。原 7b 的 900 步摘要也逐步核对，没有覆盖或重生成其输入。

旧实现保留在测试专用的 [`tactical_7c_reference.py`](../../tools/tactical_7c_reference.py)。运行前核对其两个函数的语法树与 `79db27e` 中原生产代码一致；工具同时替换舰艇电子战和航空模块中已导入的函数引用，保证旧版本确实覆盖三条调用路径。参考版本不进入生产导入链。

## 独立计时结果

同机 Python 3.14.7，使用关闭调用计数/分析器的 900 步样本，各版本各 3 次。三组顺序分别为旧→新、新→旧、旧→新；没有锁定频率或隔离其他桌面进程，原始波动全部保留。以下均为毫秒，比较本轮配对结果，不以昨日 7b 的单次值相减。

| 场景/组次 | 旧版步进均值 | 新版步进均值 | 旧版 P95 | 新版 P95 |
| --- | ---: | ---: | ---: | ---: |
| 混合 9 对 9 / 1 | 58.23 | 44.77 | 83.25 | 64.12 |
| 混合 9 对 9 / 2 | 65.40 | 44.93 | 106.69 | 64.27 |
| 混合 9 对 9 / 3 | 74.99 | 55.14 | 125.45 | 84.19 |
| 纯炮 9 对 9 / 1 | 19.07 | 20.69 | 26.41 | 28.05 |
| 纯炮 9 对 9 / 2 | 20.15 | 20.22 | 26.58 | 27.76 |
| 纯炮 9 对 9 / 3 | 20.38 | 21.28 | 27.37 | 26.41 |

混合场景三组均值分别下降 **23.11% / 31.29% / 26.46%**，P95 下降 **22.99% / 39.76% / 32.89%**；步进、发布和读取的服务调用总耗时下降 **21.90% / 30.22% / 25.01%**。混合第三组新旧版均较慢，不能把某一组的百分比承诺为所有机器或时段的固定收益。新版 P95 仍为 **64.12～84.19 ms**，高于 16.67 ms，实时目标尚未通过。

纯炮没有区域求交负载，原三组均值变化为 **+8.50% / +0.34% / +4.42%**，P95 变化为 **+6.20% / +4.44% / −3.53%**。保留这些结果，不宣称纯炮获得提速或已证明零回退；针对这部分波动，另做逐步交替的同期补测，结果单列。

纯炮补测每一步交换新旧版的执行先后，共 900 步：旧/新均值为 **17.0767 / 17.0536 ms**（−0.14%），P95 为 **20.5476 / 20.6443 ms**（+0.47%）。原 7b 摘要逐步一致，最终扩展状态相同。这次没有重现独立运行中的几个百分点变慢，不支持将原波动认定为稳定的代码回退；后续六场统一联测继续保留纯炮对照。补测的两个战局共享进程缓存，与独立运行不同，不混合分布，不以补测的发布差值申报收益。

全部 12 轮独立计时的原 7b 摘要逐步匹配，且同场景各轮最后一帧的扩展状态相同；计时不保留逐帧显示包。发布/读取原始分布、服务 CPU、来源指纹和派生汇总分别保留在 `measure/<case>/` 与 `measurement-summary.json`，不把单步/发布/读取的 P95 直接相加。

## 复现与范围

使用[测量工具](../../tools/profile_tactical_7c.py)，输出目录必须尚不存在：

```powershell
python -X utf8 -m tools.profile_tactical_7c verify artifacts/tactical-7b-20261009/mixed-9v9 artifacts/7c-verify-new
python -X utf8 -m tools.profile_tactical_7c measure artifacts/tactical-7b-20261009/mixed-9v9 artifacts/7c-measure-new --pairs 3
```

`verify` 收集逐步状态等价和诊断计数；`measure` 关闭分析器与调用计数，在同一进程中交替运行各 3 次旧/新实现，每次重建同一冻结战局，并清空跨战局的轨迹/射程缓存，步进/发布/读取分开计时。服务 CPU 只包含这些服务调用，不包含恢复、诊断摘要或测试工具开销。仍属离线固定步测量，不能代替按墙钟调度的页面运行、原生 GPU 或完整自然战斗验收。

本片验证最重的混合与纯炮两组；完整六场矩阵、自动接敌复测及四组真实页面统一复验留在后续 7c 联测。900 步窗口内未完成自然终局、完整返航再出动或保存重启，不扩大为 7d～7f 已通过。
