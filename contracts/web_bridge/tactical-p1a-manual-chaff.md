# P1a：纯炮交战主动投放箔条

日期：2026-10-14。基线：`aa301d3` 加本轮工作区。本片完成手动箔条规则补齐和专项验证，后续 P1b 公共观测能力复用也已完成。当前下一片为 P1c 炮弹碰撞增补；P1a/P1b 代码、工具、证据与规划随本次提交归档。

## 行为与范围

玩家在没有发现敌方导弹时，也可手动投放小型或大型箔条。后台提交、逐步执行判据与前端按钮一并接通；己方就绪设备正常显示“可投放”。投放仍受场景/阵营/指挥权限、设备可用性、供电、库存、装填、冷却和场内区域上限限制，执行前条件变化仍按当步实际状态处理。现有箔条设备本身无需人员，但舰艇控制资格和公共设备可用性门槛保留。

热烟和主动诱饵继续要求合法敌弹情报，敌方自动投放也沿用该条件。本片没有制定纯炮自动投放策略。

既有遮挡算法不变：箔条是会影响双方雷达的实体区域；新区域在投放当步重新进入观测与火控计算。红外或合法友舰数据链可以继续提供目标，不把这种观测误算成本舰雷达照射；航空电子干扰区的敌我过滤与反辐射源规则保持。

## 验证

- **后台 71 项相关测试通过**，其中新增 10 项纯炮箔条测试。覆盖小/大型箔条无敌弹投放、原自动策略与其他设备门槛、雷达火控在投放当步丢失及到期后的重新获取、移出区域后的探测恢复、红外/友舰共享观测及本地雷达照射区分。
- 覆盖执行时可用性变化、实际设备毁伤、冷却/缺料/区域上限/控制失效、失败步骤回滚、精确重试、暂停和代次失效。可用性理由分支使用受控输入；实际毁伤另用真实步骤验证。到期专项只将区域期限移到下一步以验证边界，不宣称跑满 45 秒。
- **前端类型检查及 49 文件 / 212 项测试通过**。箔条无敌弹时可用；其他设备门槛以及暂停、毁伤、库存等禁用状态仍生效。
- **实际 React 页面 + Python 后台流程通过**：两艘合法纯炮舰，5 公里手动部署，有限弹药，预装箔条但不带补装工程材料。真实开炮和雷达锁定后投放，模拟一次已接受回执丢失，只有一次提交/一次投放；雷达失锁后通过页面开启红外恢复合法观测。暂停/恢复不重复扣弹。
- 使用测试结束按钮结束该场并保存双方结果，关闭页面、重启后台后核对库存完全一致；再经正常准备保存进入下一场，小型箔条待发量仍为 0，没有旧区域残留。此流程不是自然终局、完整 7d 战斗或原生 Tauri 验收。
