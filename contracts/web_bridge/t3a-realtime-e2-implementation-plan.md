## 实施顺序

### E2.1：部件耐久、损毁与宿主依赖（范围内已实现）

首个交付闭环：合法部件损伤写入 → 更新独立耐久/损毁状态 → 找出受影响发动机及宿主后代 → 产生内部可用性事件 → 同边界更新能力、实际输出及运动后继状态。

1. 新增独立设备领域模块，建议放在 `backend/high_wilderness_sidecar/tactical_devices.py`。进场一次编译模块 ID、耐久上限、发动机对应索引、宿主链及反向依赖；只读资源与动态状态分离。
2. 采用现有耐久单位、合法范围及损毁阈值，复用适合提取的规则。部分伤害仍保留准确血量，但不得重新套用发动机耐久效率曲线。受损供电设备等对其他系统的间接影响留在对应依赖规则中，不能因发动机政策简化而删除。
3. 提供仅测试工具可调用的受控领域输入，携带场景身份、目标部件、操作身份和生效边界。后台产生状态版本与可用性事件；重复操作不能重复伤害，冲突、错资源和非法数值拒绝。该输入不是客户端可信状态接口，也不是炮弹命中实现。
4. 受损初态和变化后的状态均按依赖索引计算原因。自身失效、宿主失效保持独立；解除其中一种不能绕过其他有效原因。无变化时复用设备状态与派生结果，不扫描全部模块耐久。
5. 将设备候选纳入现有飞行会话的单一提交边界。步首变化影响本步输出；步内变化在收边界影响下一交付区间，不撤销已积分的速度/角速度。故障注入应覆盖投影失败与后续舰船处理失败，全部领域保持旧提交状态。
6. 明确恢复入口。正常修复必须沿用现有规则允许的对象、条件与上限；不得把测试中任意设置“可用”当作真实修复。若现有规则不允许完全损毁部件被修复，测试重建/替换应单独命名，不擅自增加战斗复活能力。允许恢复后仍走启动与响应计时。

本片验收：部分损伤、全毁、初始受损、宿主多级依赖、重复/过期/冲突输入、同边界到期与失效、失效后惯性、失败原子回滚；每个边界以独立全量账本检查能力。覆盖零贡献设备和无关部件损伤，证明没有不必要的发动机重建。人工供电等阻塞可以用于组合机制测试，但标记为未接真实生产者。

### E2.2：供电、人员、工作模式及指挥依赖（分片实施）

E2.2a 已完成供电/人员/模式变化及阶段触发、跳闸锁存与实验直控权限下的显式复位。E2.2b 已接单旗舰 CIC/遥控功能失效、生命周期、I9 失权锁存与受控退出；RTS、距离/无线模型及自动退出未纳入本片，完整 E2 尚待重建及范围审计。级联处理采用有界、锁存单调增加的候选检查，不能收敛则拒绝步骤，不在热循环做无界反复求解。

复用 `高天荒野舰艇运行时参数编译器.py` 的人员/供电分配规则和 `高天荒野舰艇推进硬故障运行时投影.py` 的阶段映射，提取为可消费已编译资源与动态状态的领域计算。旧完整投影保留测试参考，不作为新循环的逐步调用入口。

触发至少包括：相关设备耐久/模式/宿主变化、人员变化、供电策略变化、指令导致的启停，以及发动机到期跨阶段导致的人员需求或 active/standby/off 负荷变化。对共享电力或人员池，一次变化可能需要重算整个相关分配域，不能承诺所有事件均为 O(1)；域内无变化则复用结果。保留原有步内阶段顺序，不能用无界反复求解消除循环依赖。

本片同时梳理 CIC、遥控宿主、失联、生命周期和跳闸复位的受控写入与权限判断，按可验收的小块完成。正常战术推进不消耗燃料，但既有燃料不可用条件仍须明确处理。动态质量与结构脱落单列后续切片，不能把损毁部件视为质量自动消失。

验收叠加失效矩阵、资源不足时确定性分配、权限失去/恢复、阶段变化诱发断电或缺员、复位条件及回滚。保留规则与旧参考对照，新政策差异继续独立记录。

### E2.3：重建、同口径性能与进入 E3 的门槛

本片范围内已完成，见 [E2.3 实现及范围审计](./t3a-realtime-e2-3-save.md)。108 项相关测试、54 次保存重建和 12603 个续跑边界通过，读档后三负载各三轮吞吐通过。falling/跳闸/旗舰失权锁存与退出冻结均保留，未接生产者和旧完整场景状态不得静默导入。E3a 调度现已实现，下一实施项 E3c 长跑准备与验证；完整战斗/修复等领域覆盖仍不标为 PASS。

建立内部状态导出/重建合同，持久化实际设备状态、版本、推进响应与排程、权限及必要过程状态；不保存内存证明。加载严格验证政策/资源，重算依赖与能力并核对，同输入续跑一致。E2 验证内部重建，E3 再接产品文件保存、可靠请求及 UI。

扩展现有三负载验证工具，将领域输入校验、损伤写入、依赖传播和事件生成计入固定步耗时。保持两舰、600 步预热、3600 步测量、三次重复口径，单列创建、稳定步和事件步；正确性全量参考及画像单独运行。明确哪些领域已进入负载，未接领域不得用常量“正常”冒充完整场景。

E2 已接领域的失效矩阵、保存续跑、失败原子性、无变化不重算机制及包含生产者的吞吐门通过后，进入 E3 调度、快照与最小画布联调。30 分钟/2 小时长跑、E4 真实弹丸命中、E5 玩家设计出航与默认迁移仍按主计划保留。
