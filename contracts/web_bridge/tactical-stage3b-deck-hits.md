# 工作包 3b：概率甲板、模块瞄准与毁伤衔接

日期：2026-09-16。属于[首版规划](./tactical-first-release-implementation-plan.md)工作包 3 的第二片，接续分口径弹道和炮组火控。

## 已确认规则与初值

用户确认弹道能够接触的候选甲板等权，指定单层模块后，该层权重提高到 2 倍；跨甲板模块将同一份瞄准加成均分到实际占用的各层。数值仍可后续调整，不保证命中所选模块或其所在甲板。

当前[策略](./fixtures/tactical-deck-hits.3b.json)为每层基础权重 1、整份瞄准加成 1。例如，两层都在弹道上时，不指定模块为各 50%；指定第 1 甲板的单层模块后，第 0、1 甲板分别为 33.3%、66.7%。模块跨两层且有第三层候选时，权重为 1.5、1.5、1，概率为 37.5%、37.5%、25%。没有几何接触机会的甲板不会因瞄准加成成为可命中目标，其份额也不转送到其他层。

跨层模块的占用层读取实际安装格，顶部模块沿用现有顶部格所属甲板口径，不把显示体积的层号当作额外内部甲板。模块加成仅适用于发射时指定的敌舰；途中另一艘敌舰不会继承这个模块偏好。

手动射击的甲板选择同样成为概率偏好，可以清除为“不偏好特定甲板”。自动整舰瞄准默认不偏好甲板。发射后切换目标、模块或甲板偏好，不改写在途炮弹。

## 实际接触和毁伤

炮弹先按阵营与战场高度层筛选舰艇。第一次实际接触某舰任一甲板轮廓或有效外部模块时，沿当时的相对飞行方向检查整段穿舰方向，取得候选甲板并抽取一次。候选计算包含目标平动与回转，且不局限于当前一帧内能够到达的甲板，避免慢弹只能选到最外层轮廓。

每发炮弹对同一舰艇保存一次选择，抽样由战局种子、稳定弹体编号和目标舰身份决定，不随帧数、碰撞细分或失败重试重新抽取。抽中较小甲板后，仍须真实飞到其边缘或外部模块才结算。途中到寿命截止或因相对运动错过该层时，不瞬移命中，也不回退伤害另一层。

实际受击甲板决定局部装甲边、穿后平面路径上的模块或跨层模块部分、燃料槽，以及点燃尝试使用的防火填充倍率。跨层模块按模块身份去重，单次命中不因占多个格重复扣耐久。真实受击时刻仍用于同一步内多弹命中排序。全舰船壳、设备失效、损管、储罐抢修和结算继续复用既有链路。

旧几何专项允许显式固定甲板以隔离测试，生产发射全部使用概率选择。没有改变历史实例、设计指纹或库存版本；在途弹与甲板抽样不保存为战斗断点。

## 界面

- 炮组和单炮面板显示当前甲板偏好；模块选择明确标记“甲板”，与炮弹作用的上层/云层/雨层分开。
- 命中记录显示实际受击甲板、战场层、弹种、装甲结果和受损模块，并列出本发候选甲板概率及瞄准偏好。
- 概率是本发真实候选的归一化结果。弹道只接触一层时可显示 100%，不能把 66.7% 当作所有方位都固定适用的命中保证。
