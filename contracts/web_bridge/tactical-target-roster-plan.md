# 战局目标名册与战术目标列表实施计划

日期：2026-10-17；实施状态更新至 2026-10-21。P2a.1a 已推送至 `352f3e5`，1b/1c 已推送至 `540c2df`。**P2a.1d 联合验收已完成本片范围**：195 项后台、217 项前端、三版本各三组计时、固定/自动服务、组件回放和四组真实页面检查完成，详见[联合记录](../../artifacts/tactical-roster-joint-20261021/README.md)。保留当前功能与接入结构，未确认整体稳定提速；固定 1×、250 ms、完整战斗与原生目标仍未通过。下一片为 [P2a.1e 舰对舰事件驱动侦测](./tactical-p2-load-and-plan.md#6-p2a1e-舰对舰事件驱动侦测)，先分类归因，再做关系复用原型；1e 尚未实施。1d 的参考 `352f3e5` 已含 1a 名册，不能将本轮增量比较当作整套名册的净收益。保留 1a 的 `05247c1` 历史验证记录；后续 P2a.2、P2b、P2c 的相对顺序不变。

目标是在一场战斗内维护轻量目标名册，按成员和少量元数据的变化更新；侦测通过名册访问当前实体，并提前筛选阵营和高度层。同时将名册接入战术界面，显示非玩家阵营的目标，已发现的正常显示，未发现的灰色显示。

## 1 范围与显示规则

用户已确定：战局内持续使用目标名册；具体资料由实体持有，侦测按需读取；名称、阵营、高度层作为低频元数据保留；名册支持战术界面展示非本方目标。目标类别纳入首轮实施，用于规则选择、分组和过滤。

首轮按以下方案落地细节：

- 名册包含当前可参与侦测的舰艇、在空飞机、有耐久的弹体。机库和货舱中的飞机、尚未实际进入场景的待发射弹不登记；无耐久的小口径弹继续按现有物理效果显示，不新增锁定资格。箔条和电子干扰区继续由环境系统维护。
- 名册列出所有非玩家阵营的活动条目，公开名称、类别和存在信息。条目的加入、退出会改变列表和计数；退出本身不被解释为已击毁，不公开回收、撤离、损伤等详细原因。
- “已发现”沿用当前操作舰实际可用的观测，包括符合现有规则的数据链共享。切换操作舰后重新合成显示状态，不将全体友舰未共享的情报直接合并。
- 未发现目标只显示名称、类别和“未发现”。位置、距离、速度和高度层都由合法观测提供；内部名册保存的实时高度层不直接显示给未发现目标。
- 有有效观测的目标正常显示；失联目标灰色标注“失联”，在现有记忆期内可查看最后观测位置。记忆过期但仍在活动名册中的目标显示“未发现”，这里表示没有当前可用观测，不额外维护永久发现历史。
- 名册移除不会主动清除既有观测记忆。退出目标的历史行按原观测失效和记忆规则处理，名称/类别可从上一条目保留到记忆结束；不从实体实时状态推断其结局。

展示范围的增加是一项明确的界面功能变更。探测频率、跟踪容量、火控资格、导弹兼容、电子战与实际战斗结果按原规则保持。

## 2 名册数据与访问方式

| 字段 | 内容 | 更新时机 |
| --- | --- | --- |
| 目标身份 | 实体家族与原始唯一编号，保留编号的字符串/数字类型 | 登记、退出；避免不同实体家族编号冲突 |
| 实体访问入口 | 在当前候选阶段定位实体的轻量句柄 | 阶段绑定变化；不长期指向已被替换的状态对象 |
| 名称 | 舰名；飞机名称或型号加编号；弹药名称或类别加编号 | 登记时生成，名称实际变更时更新 |
| 阵营 | 实体所属阵营 | 登记及真实归属变化时 |
| 当前高度层 | 当前实际所在层 | 跨层生效时，包括主动换层、强制下降和弹体跨层 |
| 目标类别 | 舰艇、飞机、导弹、炮弹、炸弹 | 登记时确定；与具体型号分开 |

名称不承担唯一定位职责。舰名复用场景既有命名；没有独立名称的飞机和弹体在登记时生成稳定标签，不在每次扫描时拼接。预警机、电子战机、战斗机和轰炸机都属于“飞机”；普通炸弹和制导炸弹首轮同属“炸弹”，详细型号按需读取。

现有炸弹使用了导弹运行结构，名册的展示类别必须依据弹药定义识别。名册 `category` 与现有观测 `kind`、武器 `target_kinds` 通过显式映射衔接，首轮保留旧观测和武器兼容语义；不能因显示分类修正改变炸弹的探测距离、锁定资格或毁伤。第一版不增加目标尺寸、推进状态、辐射开关等额外索引字段。

位置、速度、朝向、耐久、推进状态、雷达/红外特征、挂载和型号资料继续由实体及目录持有。侦测取得目标后连续读取所需字段，不按每个属性重新遍历舰队或复制整份型号数据。昂贵的派生计算只在输入确实相同的阶段复用。

名册是权威实体的派生索引。初始化、恢复和一致性校验允许从实体重建；正常运行通过实体已有的更新路径登记变化，不用每步构建完整 `Target` 列表再深比较。

## 3 生命周期与候选阶段隔离

战局级名册保留已提交版本；单次模拟的增删和元数据修改先记入候选改动，整步成功后才提交。候选实体通过当前阶段的访问上下文解析，不能仅凭相同 `fixed_step` 共用读取结果。

| 事件 | 名册处理 |
| --- | --- |
| 战斗初始化或重建 | 按既有确定顺序登记活动目标；建立阵营与高度层分组 |
| 炮弹/导弹实际生成、飞机起飞 | 在原有生效边界登记，不让新目标提前被本步较早的扫描发现 |
| 飞机换层、舰艇主动/强制换层、弹体跨层 | 更新层字段，将条目移入新层分组 |
| 受击但仍存续 | 耐久留在实体中；名册不因每次耐久变化重建 |
| 弹体命中/拦截/过期、飞机回收/坠毁、舰艇离场/坠毁 | 在对应阶段移出活动名册与分组；独立观测记忆仍按原规则处理 |
| 飞机再次出动 | 重新绑定当前实体；保持原始飞机身份与原有观测行为，不继承旧句柄 |
| 同一步投放箔条、干扰源移动或设备关闭 | 环境或能力输入更新；即使名册未变，也要重新执行需要的可见性判断 |
| 候选步失败、命令拒绝或精确重试 | 丢弃未提交改动，不留下幽灵条目、重复登记或已推进的目录版本 |
| 战斗结束、释放、重建场景 | 清理当前名册及阶段引用；新场景不会复用旧身份缓存 |

起飞等命令路径、结算/强制结束和暂停期间允许的操作也需要纳入生命周期盘点，不能只覆盖固定步主循环。恢复后的索引按已恢复权威实体重建，不将进程对象引用写入保存数据。

名册按原始候选顺序遍历。分组筛选后保留相同的相对顺序，避免同优先级目标择优变化；活动索引中及时移除已退出条目，历史条目不参与持续扫描。

## 4 侦测筛选与观测样本

查询顺序为：选取非同阵营目标 → 按该消费者允许的高度层筛选 → 按适用规则筛选类别 → 读取必要实体字段 → 原有距离、特征、射界和干扰判断 → 跟踪分配与观测采样。

首轮建立阵营和高度层分组，分组只保存条目引用。目标类别用于选择规则和界面分组，是否再维护类别索引由访问次数决定。普通雷达不因为某武器只能反舰就排除飞机或弹体。

当前普通侦测允许同层与相邻层：上层读取上层和云层，云层读取三层，雨层读取云层和雨层。飞机任务、武器攻击和导弹导引另按各自跨层规则取候选，不套用一个全局“只看同层”的条件。

威胁优先级还依赖其他舰艇运动，不能仅以弹体状态未变为由沿用。距离粗筛若使用上限，必须包含舰艇外形/朝向和飞机特征可能带来的增益，不直接使用传感器标称距离截断大反射目标。

实时实体读取与观测样本分离。只有需要更新某条观测时才生成不可变样本；旧航迹、数据链传递和失联记忆继续持有原采样值。当前 `Target` 可在迁移期保留为样本格式，禁止将其改成所有观察者共用的可变实时对象。首轮保持现有扫描和采样间隔。

## 5 发布契约与界面接入

内部名册可保留双方目标与实时层字段，对外在 `gunnery.target_directory` 增加单份非本方目标摘要。接口为 `gaotian.target-directory/v1`，包含战局 `epoch`、独立 `revision`、活动 `entries` 和历史元数据 `remembered`。每条仅含 `key`、原始 `target_id`、`name`、`category`；`key` 是实体家族与带原始类型编号的 JSON 数组字符串，区分同名、同编号不同家族以及数字/字符串编号。命令仍提交原始目标编号。摘要不附带实时位置、高度层、耐久、实体句柄或完整型号资料。

目录摘要使用独立修订号和现有发布节奏：成员或对外元数据变化才更新摘要；内部换层不应触发一份内容相同的名称目录重建。观测更新继续走现有通路，界面按选中观察舰合成状态。同一步内关机、箔条或命令也可能改变观测，修订不能只看步号。首轮使用自包含摘要并在服务端复用未变化内容，不新增需要客户端追赶的增量事件协议；重连和丢失一次发布后仍可直接恢复。

`remembered` 仅保留本方合法观测仍引用的退出目标元数据；前端只显示当前操作舰实际持有的联系人，历史记录不计入活动数。若短命目标从未进入已发布摘要，以合法观测的类别和编号生成后备标签，不查已消失实体补充隐情。此前已发布的炸弹类别和机型名称保留到联系记忆消失；观测顺序变化不会重新排列历史元数据或递增修订号。发布值按只读快照使用，后续更新不原地修改先前响应。

首版将火控面板顶部“已知目标”升级为“目标名册”，提取为独立组件供其他位置复用。沿用火控面板与画布的布局关系，切换火炮、导弹、航空子页时保持可见，不并列显示第二份重复列表。

- 按类别分组并显示活动条目数；舰艇和飞机默认展开，弹体默认折叠，提供“全部/有有效观测”过滤。失联记忆中的已退出条目单独标明，不计入活动数。
- 分类内按稳定登记顺序排列，不按实时距离或发现状态不断重排；每个展开分类按每页 12 条分页，保留完整计数和可访问条目。
- 名称、类别始终可见；灰色同时配“未发现/失联”文字。有观测时才补充观测层、速度、年龄等信息。
- 有效目标沿用当前火控锁定和双击定位通路；没有指挥机的目标仍可正常显示为已发现，但不因此获得舰级锁定资格。武器自持火控继续走现有专用规则。
- 灰色条目不发送锁定或分配命令；未发现目标不能定位，失联目标只能定位仍有效的最后观测。点击目标不切换本方操作舰，不改变舰艇航行层。
- 名册新增条目不会在画布生成未经观测的目标、插值轨迹、距离或方向提示。后端命令仍验证实际观测及当前资格。
- 对外摘要缺失的旧测试快照走现有已知目标列表，不从原始全场姿态拼出灰色条目的动态详情；正式新版本必须提供摘要。
