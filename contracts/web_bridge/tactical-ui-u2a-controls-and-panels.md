# U2a：即时旗舰操纵与功能面板整理

日期：2026-09-20。状态：本片已接入并通过范围内验证。下一片 U2b 处理图标、观测展示和其余功能整理，U3 做联合验收；整包 U 尚未完成。火控优化 F 按用户要求排在 U 完成后，当前未实施 F。

## 已确认并接入的操作

- 车钟档位垂直排列，点击立即下令、当前档位高亮；前进／倒车独立选择。
- 左右转向位于车钟两侧，各设半速与全速 toggle。点击其他方向或档位直接切换，再点当前档位进入自动回正。
- 回正指消除角速度，使用现有转向推进器提供反向力矩并经过发动机响应、人员、功率和安全约束；不恢复旧航向、不瞬间抹去正在旋转的角速度。两侧实际转向输出归零且角速度低于 0.02°/s 时，才清理残余数值到零。无可用反向推力时显示受阻。
- 调整车钟保留当前转向／回正；换层独立。停车保留惯性，制动沿用原平移制动并开启回正，解除制动不恢复先前转向。
- 面板始终控制旗舰；查看友舰时，旗舰的车钟、转向与换层不会误发给友舰。暂停或失权时禁用即时操纵。使用既有未来步命令及回执，未确认时阻止重复提交。
- 保留附着图标折叠与未悬停／聚焦时半透明；面板不参与画布大小或相机计算。

## 功能整理

- 按舰艇保存并恢复舰务／武器子页、导弹发射／在途／后勤页、选中发射器以及感知／电子对抗展开状态，作用域为本场战局。
- 货舱显示当前友舰真实货物数量、预留、可用量和共用仓容；弹药库列出资源、容量及可用状态，燃料／损管储量复用既有投影。未添加战中无限补满或战前维修。
- 货舱快捷入口可直接展开火控并打开导弹后勤；火炮组批量目标操作保留。完整导弹性能和炮击规则收进详情。
- 下坠、火灾和已预测撞舰威胁提供选舰／定位／相应功能页快捷入口；共享观测的同一威胁去重，只列本方存活参战舰艇。警报聚合已有数据，不新增每帧威胁解算。
- 显式画布瞄准／选点显示退出提示；Escape、切舰、切武器页或关闭火控会清理瞄准及待发送指针操作。查看火控目标不隐式给武器发令。

## 接口与兼容

- `gaotian.tactical-propulsion-control/v3alpha1` 在原方向推进命令上新增布尔 `automatic_yaw_brake`。开启时不能同时请求手动转向。未开启时继续输出原 v2 字段，原 v2 输入仍有效。
- 新自动回正接入当前实时 `SimplifiedFlightSession`，不把旧实验控制界面宣称为已经重构。检查点保存、恢复期间保留回正状态与发动机响应。
- 实时外层响应新增 `requested_control` 与 `yaw_brake_status`（`braking`／`settled`／`unavailable`／空），用于显示权威操纵与反馈。
- `view.gunnery.stores` 为只读友舰库存投影，复用已有库存汇总，不复制完整存档。无此投影的旧视图仍可显示已有库存概要。
