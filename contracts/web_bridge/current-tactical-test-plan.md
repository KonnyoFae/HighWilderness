### 5b 部件准备回归入口（2026-09-17）

- 选择一门有余弹的炮，补满本舰全部火炮：不同口径各用自身弹种，其他友舰/敌舰库存不变；缺弹不足整批仍能补齐，逐项材料向上取整。满容量再次补满不消费。
- 选择弹药库、普通/填充燃料槽或部分用过的损管设备，验证单件/本舰同类补满；先用舰内原料，必要时从供给自动装载，仍检查可用弹药库/货舱容量。
- 选择未毁受损部件：显示修满费用、可取消维修安排；保存时修复并扣供给工程零件，库存不隐式填充。已毁部件不可修，已毁升力罐战中紧急抢修规则保持。
- 缺料、容量不足或同类中含不可补给部件时，预览显示错误且保存不可用；舰艇与供给均不部分变化。补满/维修草稿回执丢失、保存回执丢失均能安全重试。

## 范围与已有结论

当前已开发的全部内容均属于战术模式，包括舰艇编辑、战前准备、交战模拟与演出、损管及战后保存；战略模式尚未开始开发。ST0 是当前系统为未来调用提供的双方入战和结果关联接口，没有正式战略遭遇界面。

未来大部分战斗是中远距离交战，由战略模式操作与战术模式近距离模拟、演出两部分构成；玩家绝大部分游戏时间在战略模式经过。单场战术模式最大预期持续时长不超过 **15 分钟**，超过须整体调整游戏平衡，不新增强制超时结束机制。两小时测试需求彻底取消，不保留必测、可选、按需或恢复条件。依据：[总规划第二章](../../高天荒野游戏规划归档.md#二战略层与战术层的战斗关系)。

- O4 已由用户确认实际完成，不再重开三舰往返、四类安装和留档验收；编辑器只在新功能关联或出现可复现回归时定向检查。
- 本次结构预检已通过前端类型检查及 85 项测试、测试总入口自身 3 项测试；这是当时的结构预检记录，不代表后续入口可用性验收。
- OP1、ST0、武器、损管及资源各片已有专项和浏览器/桥接验证记录。已有通过结论保留；本清单中的实际操作复测用于确认当前组合体验，不能把“尚未本轮复测”写成“功能尚未实现”。
- E3c 已完成的 30 分钟后台测量仅为历史工程证据，不要求重跑，也不代表单场玩法目标。

| 保存战后舰船状态 | 点击“保存全部战后结果” | 所有参战舰船状态一起保存；既有损伤、余弹、资源与未灭火情保留，不免费维修或补给 |
| OP1 返回入口 | 保存前后观察“管理战后库存与下一场准备” | 未保存当前结果时禁用；保存后返回自建舰准备列表；查看已保存的历史结算不能解锁当前未保存场景 |
| 重启与下一场 | 返回准备、重启后台、重新准备原舰并再次入战 | 原舰身份、战损与余量连续；旧准备回执不能替代当前修订；不误入技术测试舰重新部署流程 |

“保存战后舰船状态”指本地实例持久化。当前界面需要手动点击保存，本轮按这个已实现流程验收，不将其改成自动保存。它不表示战略奖励、地图占领或世界战果应用。

最小操作样本是同一舰船连续两场的 A→保存→重启→B 往返；无需每次重新做完整编辑器验收。现有准备入口仍使用技术测试敌舰，双方持久实例的验收另见第三部分。

## 二、结合上述交战验证已接入的新功能

分为几个明确样本，不要求一场同时触发所有机制。界面验证可见反馈与操作；概率、事务回滚及难以稳定触发的毁伤由已有专项测试核对。

| 功能组 | 本轮重点 | 边界 |
| --- | --- | --- |
| 普通炮、穿甲弹、燃烧弹 | 自动选舰/模块目标、手动转炮及射击；实际炮向/射界；下一批弹种选择；普通资源与特殊合金/高能燃料成本；真实命中、装甲和模块损伤 | 待发弹与在途弹不因选择下一批弹种变种；受阻原因清楚；降级火控通过专项复核，不要求玩家反复破坏雷达碰运气 |
| 概率甲板与模块偏好 | 炮组指定模块后观察偏好与实际命中；手动偏好可清除；记录区分战场层、舰内甲板与本发候选概率 | 指定甲板不保证命中；跨层模块均分加成；跨帧不重抽，真实飞到抽中甲板才结算；装甲、模块、燃料和防火填充均读取受击层 |
| 表面火灾与蔓延 | 新导入舰装填燃烧弹，未击穿引燃舰外；同甲板邻区传播；查看火点与损管当前扑救位置；保存未灭火情进入下一场 | 不跨甲板或直接由舰外传入舰内；子火不在出生步连锁传播，寿命不超过来源；一具设备同一时刻扑救一处，暂停和失败步不推进；旧型燃烧弹不误标为新效果 |
| 结构材料与逐层填充 | 设计保存、准备与入战信息一致；结构冗余影响最大船壳耐久；每层单一填充、净容量、货架容量、防火效果分别生效 | 不重开 O4；比较同条件样本。防火只降低新点燃概率，不以单次未起火宣称验证通过 |
| 损管、火灾与维修 | 旗舰设备启停、手动/自动目标、资源与零件、灭火优先、维修反馈、暂停及跨场保存 | 不自动重建已毁模块或独立填充燃料槽；普通弹、穿甲弹不承担燃烧弹的点燃验收 |
| 灵烷燃料 | 准备装卸、逐槽存量、推进和转向零油耗、真实槽损毁后的一次性损失及保存 | 普通掉血不漏油；不因无关船壳掉血按比例扣油；不同槽独立，不能用高能燃料货物代替灵烷 |
| 近防炮与弹体耐久 | 30 毫米炮组开关；不同速度/高度的来袭弹、多炮齐射、雷达失效、缺弹、落空补射、保存与下一场 | 只自动处理有耐久的预测撞舰威胁；三档排序，已足量在途时等待/转移；实际命中才扣耐久，归零无后续伤害；落空弹可伤敌舰、不误伤友舰 |
| 人员与岗位 | 舰况查看人员总数与逐模块配员；人员舱受击、内部火灾、殉爆后检查伤亡记录；保存并再次入战 | 负伤/阵亡分别记账、伤员退出可执勤；小数累积，按岗位优先级配员；人工功能降效/停机，自动化功能保留；无免费治疗或补员 |
| 货舱与资源 | 缺料、货舱损毁导致超容、余量和预留、重新准备及下一场 | 超容保留现有货物与预留，禁止新增装载，允许消费及保存；不删除货物伪装容量正确 |

新功能均已有范围内实现与证据。这里核对联合操作和状态延续，不要求把技术参数直接验收为正式平衡数值。

### 升力冗余、下坠与储罐紧急抢修（2d 已接通）

按[升力冗余专题](./tactical-lift-reserve-design.md)明确计时与抢修参数后验证，不用原 D1/H5c 通过记录代替：

| --- | --- |

| 下坠触发与分段 | 负冗余才新触发，零冗余不新触发；缺口越大计时越短，按实际完成时刻逐层切受击层，雨层保留末段抢修机会 |
