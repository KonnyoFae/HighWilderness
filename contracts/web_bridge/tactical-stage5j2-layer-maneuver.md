# 5j.2 实际换层、重力与连续碰撞

日期：2026-09-18。状态：本片已接通并完成范围内验证；下一片为 5j.3 火控与拦截协调。设计和整体顺序见[5j 实施计划](./tactical-missile-layer-pursuit-implementation-plan.md)。

## 交付行为

- 全部当前导弹共用连续高度/俯仰状态，相邻层间距 5,000 米。导引头有效锁定中的目标层变化，以及型号既有记忆跟踪，可驱动实际逐层追击；途中新情报改变目标层时保留现有位置、速度和姿态。助推仍不转向。
- 上爬受重力减速、下潜受重力加速。发动机推进上限限制发动机做功，不截掉已有速度或重力提供的增速；水平与垂直转向共享过载预算，转向损耗按既有 1G·秒扣 9.8 米/秒规则计入一次。初值为常规弹最大爬降角 30°、拦截弹 45°，均逐型可调。
- 轨迹控制根据目标的水平位置和目标高度计算爬降角，并预留拉平距离。近处目标仍可能超出剩余时间/机动能力，换层追击不等于保证命中。仅有实际高度达到相邻层锚点后才切换碰撞所属层；上下两层间必须经过中间层。
- 无动力上爬总速度达到默认 50 米/秒阈值时，在实际阈值时刻结束上爬，保留高度及完整速度向量，转入受重力支配的回落；不瞬移、不自毁。回落可继续以现有气动能力水平转向并消耗速度，先返回本段原层，再逐步拉平。阈值支持型号覆盖。
- 上爬失败的目标身份记入该弹整个飞行过程；重新捕获或改回同一目标不能清除，不阻止该目标回到同层/下方后被正常攻击。失锁直飞型逐步拉平，记忆型继续最后已知层/区域，均不读取隐藏的新机动；强制回落优先。
- 固定绝对到期步、VLS 等待不占寿命、初始本层/相邻层发射和跨层降速、友舰穿透及库存结算继续沿用 5j.1/既有规则。

## 运动与碰撞衔接

`missile_maneuver.py` 提供控制律、带垂直状态的不可变提交结果及统一轨迹；`missile_flight.py` 保留平飞解析路径，只有垂直机动进入新路径。正常机动按固定 60 Hz 边界采样控制，重力沿速度方向的作用在区间内解析积分；同一路径用八点高斯积分提供水平和垂直位移。上爬失败后的无转向回落采用解析重力轨迹，带水平转向的回落采用最大 1/240 秒内部 RK4 积分。内部积分不增加全战场权威步频。

轨迹记录一个固定步内经过的层边界，命舰、诱饵接触、弹体拦截和最终运动状态共同读取这条路径。舰艇主动换层也按旧读条剩余时间取得步内完成时刻，不能拿步末新层倒推整步。接触和到期保持原先“严格早于到期/更早命中事件”的顺序，层切换不创造双层命中或无敌期。

毁伤使用命中当时的总相对速度。侧甲法向仍来自平面甲板几何，入射角由完整速度归一化计算；舰内后效射线继续用单位水平投影，防止垂直速度重复计入能量或扭曲后效长度。层间空域没有新增连续三维舰艇碰撞。

## 可见界面

在途导弹卡片新增上爬、下潜、回落、拉平、目标层、剩余垂直距离及俯仰角；显示低速失败原因与“本次飞行不再向该目标上爬”。已完成垂直任务、仅在拉平时不再显示不会归零的垂直剩余距离。总速度和水平速度继续分别显示。性能页说明发动机推进上限与下潜增速的关系。
