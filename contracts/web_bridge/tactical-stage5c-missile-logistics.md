# 5c：导弹型号、发射器与导弹库

日期：2026-09-17。状态：已接通目录、真实库存、战前/战中后勤操作与结算；导弹发射和飞行仍属于 5e，感知/火控属于 5d，电子对抗与专用自动拦截属于 5f/5g。

## 本次确认的规则

- 战前核对显示总准备耗时，保存时统一完成作业；不在准备页等待真实时间。界面按计划顺序处理每舰操作，各舰同步准备，取最长用时；同库内部仍并发组装。此段时间不推进战场伤害、火灾、维修或燃料消耗。
- 取消进行中的原料组装/装填，全额返还原配方并清零进度；取消整装弹转移则退回原弹。退库无空位时先等待实际腾位，导弹留在退回作业中，不复制弹体。
- 回收原料超出货舱容量时全部保留，禁止新增货物装载；已有材料仍可用于组装。
- 同一导弹库只选一种型号，库存可保留该型号不同战斗部，分别计数、共用库容。需要接收入库且满库时，先拆解编号最早的现有整装弹；单纯达到满库不会自行拆弹。没有兼容的完好导弹库时，整装弹退库等待，不改为免费退料。

战前准备点选发射器或导弹库会进入导弹页，可选型号/战斗部、组装一批或补满、装满单具或本舰全部发射器、卸弹、拆解、取消作业与清空本舰准备计划。核对预览后一次保存，缺料整次不提交；操作与提交均有持久重试凭据。

战前准备目录新增[炮塔式导弹后勤测试舰](../../舰艇数据/舾装方案夹具/炮塔式导弹后勤测试舰.v1.json)及[VLS 导弹后勤测试舰](../../舰艇数据/舾装方案夹具/VLS导弹后勤测试舰.v1.json)，均已通过真实目录导入服务。它们初始无免费导弹，需要在准备页组装/装填；可分别添加到双方，无需先改装自己的设计。

战局新增导弹页，按所选己方舰艇管理组装、装填、卸弹、回收与允许的战斗部切换；敌舰只读。普通发射器不能战中换战斗部，复合型号与 VLS/进阶型号按配置允许。作业使用真实材料，并受设备、宿主、供电及岗位效率约束；缺料排队，失效暂停。型号只能战前调整，且须先清空库存/作业。

每枚弹具有稳定编号和型号/战斗部/来源；原料投入后进入在制库存，转移装填时从库中移除，完成后才进入待发库存。原料直装卸弹退原配方，整装卸弹退原弹，换战斗部时再拆解原弹，不同时领取弹体与原料。库毁时整装与在制库存按当量计入同舰同甲板殉爆；空库不爆、同一步先毁伤后完成、不连锁，被毁库存不退料。已转移到发射器的导弹不计入库内殉爆。

战斗结束保留导弹未完成作业及进度，不沿用火炮结算时完成装填的行为。下一次准备可统一完成这些作业，直接再入战则继续推进。旧舰艇仍使用原资源政策与库存格式；新导入采用 5c。目录兼容覆盖现版本、加入导弹前、加入新火炮前的真实目录代际。

## VLS 画布安装修正（2026-09-17）

## VLS 水平禁射误判修正（2026-09-17）

用户继续指出 VLS 不是炮塔，无需计算水平净空角。此前编辑器对所有武器统一从安装底层求水平射界，VLS 自身上方的甲板让结果成为 360° 禁射。5e 实际发射已按 `launcher_kind == vls` 跳过转角与水平遮挡，但初始化仍计算了一份无用的炮塔禁射角。

现编辑器从当前导弹准备政策读取精确原型/版本/内容对应的发射方式，领域预览和画布预览均将合法 VLS 标记为 `vertical_launch`，不调用水平射界求解，也不显示水平射界开关、禁射圈和遮挡投影；缺少精确导弹类型绑定时显示未接入，不能猜测为炮塔或 VLS。战局初始化也跳过 VLS 水平射界计算。普通炮塔和炮塔式发射器仍按原规则判定，垂发的安装、射程、作用层、库存和设备工作条件仍有效。没有改动原型内容、指纹及旧设计格式。
