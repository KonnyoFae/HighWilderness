# H5a 边缘空间预览合同与验收

日期：2026-09-07。结论：H5a PASS；接续 O1/O2 舾装基础。

## 权威口径与版本

每层边缘空间为规范船壳区域减去该层**全部完整内部安装格**的并集。空置整格仍留给舾装；区域不依赖已安装模块。Python 按顶点高度和安装格行边界分带，返回互不重叠的三角形/梯形，保留来源区域身份。片区只是显示分区，不代表独立油箱。面积总和必须等于船壳面积减去完整格数乘 25 m²。

`HullEditorDocument.preview(include_edge_space=True)` 显式返回 `model.view_interface = gaotian.hull-editor-view/v2alpha1`。默认不传参数仍返回旧 v1 完整结果；sidecar 船壳会话统一请求 v2。会话信封、规范船壳资源、安装空间、质量与历史派生合同均不变。

合法预览的 `model.decks[].edge_space`：

```json
{
  "interface": "gaotian.hull-edge-space/v1alpha1",
  "pieces": [
    {"region_id": "deck.0.region.0", "vertices_m": [[-7.5, -40], [7.5, -40], [7.5, -37.5], [-7.5, -37.5]], "area_m2": 37.5}
  ],
  "area_m2": 37.5,
  "gross_volume_m3": 187.5
}
```

示例只说明字段与单位。每个片区顶点为米制坐标，面积为 m²，整层毛体积为面积乘现行 5 m 层高。毛体积未扣除装甲、骨架、甲板、容器与隔离设施，不能当作净填料量或实际燃料容量；装甲厚度仍不内缩安装格。

## 前端状态

- 默认开启橙色“边缘余量”叠加，可独立开关，不修改船壳或修订；只画当前甲板，下层参照继续半透明显示。
- 显示本层面积和毛体积；合法零余量显示明确的零和说明。
- 本地绘图、拖动、对称替换预览、提交中及非法权威草稿均隐藏余量与数值，不借用最近合法预览冒充当前结果。
- 旧版本、未知版本或缺失/畸形数据视为不可用并提示，不转换成零。
- 撤销、重做、恢复、保存和重开统一从规范源重建预览；不把派生片区写入资源。

## 实际桌面验收

通过 computer-use 原生输入检查 Tauri 调试应用，后台实例 `backend.2ffdeeee001244f0a79b079a6d2373dc`：

1. 打开常规有人舰，deck.0 显示边缘面积 775 m²、毛体积 3,875 m³；橙色余量位于船壳边界与绿色完整安装格之间。
2. 关闭再开启“边缘余量”，橙色分区消失再恢复，安装格保持，资源仍为干净修订 0。
3. 切至 deck.1，显示两处分离区域，边缘面积 50 m²、毛体积 250 m³，同时保留 deck.0 半透明参照。
4. 将右侧区域端点从 `(7.5, 20)` 拖至网格上的 `(15, 20)`，形成非对称非法修订 1；保存/另存禁用、橙色填充及面积/毛体积隐藏，面板提示等待合法提交，下层参照仍可见。
5. 撤销后合法修订 2，与源资源一致；面积 50 m²、毛体积 250 m³ 和叠加恢复。应用保持打开方便继续测试。
