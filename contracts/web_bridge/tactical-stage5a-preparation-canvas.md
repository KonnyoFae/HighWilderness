# 5a：双方编队画布、测试距离与真实入战

日期：2026-09-17。范围：工作包 5 的第一片。接通既有火炮舰的双方准备流程，导弹及新感知系统仍按 5c～5g 推进；本片不代表工作包 5 完成。

## 已接通

- 独立战术入口进入新的准备画布：敌方在上、我方在下同时可见，左侧加入舰船、右侧部件面板。阵营分页只切当前编辑方，点击另一方舰艇会同步编辑方；图形来自实际设计，按甲板显示，可缩放、拖动排布、输入局部坐标/朝向及指定双方旗舰。
- 导入文件选定后立即显示文件名、目标阵营和“正在加载”。成功自动加入，不再二次勾选；导入任务固定阵营及实例编号，换页不改变归属，回执丢失后原请求重试不重复创建。失败可重试或取消并重新选择文件。
- 点选具体部件保留舰艇/模块身份，自动进入火炮、导弹、设备、损管或货舱页；现有弹药、燃料、货物、预装填和损管准备复用原草稿/核对/原子保存。导弹页明确尚待接入。舰内物资以双方统一草稿保存，未完成时锁定增减成员，排布仍可编辑；保存后可直接入战。
- 测试初始交战距离支持 **0.001～1,000 公里**，初值 1 公里。以各自旗舰为原点平移舰队，双方旗舰分别位于 `±距离/2`；内部位置差及朝向保持。上下视区展示局部排布，屏幕间隔不表示真实距离。无效数值明确拒绝，配置随重启保留；不修改正式 50/25 公里交战/撤离规则。
- 新入口调用 ST0 双方持久舰艇入战，不再追加固定敌舰；保留旧专项部署接口供历史实验使用。部署允许舰体重叠，沿用不互撞规则；保存双方实际战损、库存与身份，返回准备后可直接再战或重新配置物资。
- 新测试供给初值：弹药资源 1,000,000、当前每种货物 100,000、灵烷 10,000,000。旧仓库不因读取自动补满，左侧测试供给池可以显式设置补充目标；只补不足，不清掉超出目标的余额，不改舰内库存，操作身份保证重试不重复补充。现有材料种类保持真实目录，新增导弹配方材料在 5c 补齐。
- 清空测试入口一并清除新编队配置及供给补充记录；已保存设计文件仍保留。移除物资草稿入口现在可幂等重试，不撤销已保存库存。入战回执查询支持双方遭遇，避免成功入战但丢失回复时再建另一场。

## 数据与限制

新增 `gaotian.tactical-test-scene/5a-v1`，保存场景修订、距离、当前准备引用、双方旗舰和舰艇局部位姿。仍由原 P3 保存舰艇库存与耐久，未增加第二套舰艇状态。后台从配置生成 ST0 输入，使用当前保存修订并在真实入战时复核占用、身份与状态。

接口为 `tactical.preparation.scene_read / scene_save / scene_encounter / supply_replenish`，已加入桌面桥接白名单。场景保存采用修订比较与原请求重试；供给补充使用独立操作身份和回执。

当前准备、双方入战与旧技术部署共用 **16 艘总数**边界；它是目前的工程限制，尚未完成 15～20 艘及接近 30 艘的规模验收。本片界面样本为三舰、两场交战，不宣称规模或导弹性能达标。
