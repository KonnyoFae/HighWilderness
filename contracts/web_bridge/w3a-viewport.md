# W3a 共用二维画布

2026-09-07。PixiJS 8 WebGL + React 属性面板。沿用 W2b 会话 v2alpha1 与实例/修订过滤，不新增领域命令或改变资源保存格式。

## 显示与交互

- 直接显示当前草稿的甲板区域，世界坐标单位米，X 向右、Y 向上；屏幕位置以 CSS 像素计算，渲染分辨率跟随 devicePixelRatio。
- 滚轮以指针为锚点缩放，按钮以画布中心缩放，范围 0.5—64 px/m；拖动平移，适应船壳重置视野。
- 安装格大小为五米，中心位于 5*n、边界位于 5*n+2.5；亮线显示安装格边界，暗线显示半格辅助线。端点候选坐标强制吸附至 2.5 m，无关闭选项。极远视野简化显示为 25 m 间隔边界线，不改变吸附规则。十字标记只表示候选坐标，不写入船壳。
- 端点在八个屏幕像素范围内优先选中，重叠区域按绘制逆序选择；空白点选/Esc 清除选择。区域列表提供非画布选择入口。
- 甲板切换、区域/端点属性、结构材料、检查结果与诊断路径定位。可定位的诊断切换对应甲板并聚焦区域/端点。
- 非法草稿使用橙色轮廓，不以旧合法结果伪装当前修订；合法性与派生仍由 Python 判定。
- 按需重绘，无常驻动画 ticker；卸载时释放观察器、事件与 Pixi Application。缩放/选择不会创建领域修订。
