# F1/F2：固定对照、同一步求解复用与弹道反解

2026-09-20。首片已实现并通过本页范围内验证。下一片为 F3 搜索／跟踪／射击分离和稳定错峰，然后 F4 近防滚动预测、F5 实际界面联合验收。**本页不宣布模拟落后已解决，也不代表 F 整包或最终舰队规模通过。**

## 实现与边界

- 自动选敌与随后的瞄准共用一份当步求解缓存，键包括目标／模块、完整观测、炮口位置、继承速度、弹道配置与跨层倍率；无解结果也可复用。输入不同重新计算，不能把同舰多炮的炮口或旋转速度视为相同。
- 缓存不跨固定步存在，也不代替目标有效性、射界、对准、弹药和其他开火条件。候选步骤失败则整份缓存丢弃；计数只在步骤提交后更新。新增内部诊断 `fire_control_metrics`，记录请求、实际求解、缓存／无解命中及解龄（本片始终为零），不加入存档或前端状态。
- 对现有分段线性 Mach–Cd 曲线预编译各段系数。在每段 `k(v)=a+bv` 下解析计算距离和耗时，最多经过九个速度区间，替代每次瞄准迭代从头进行大量 0.1 秒积分。系数缓存最多 128 个配置，不按任意浮点初速无限缓存。
- 这是预测计算的改进：原预测采用 0.1 秒中点近似，现按同一连续阻力曲线反解；不承诺预测浮点值逐位一致。实际弹体仍按原 60 Hz 中点推进、连续扫掠与碰撞；寿命、显示参考射程、弹种、射速、资源和毁伤规则未变。
- 搜索／跟踪仍逐步执行；未引入频率限制、待机简化、跨步射击解或新队列。排队耗时及跨步失效原因随 F3 建立时补充，近防预测及导弹制导未改。

## 固定对照

[测量工具](../../tools/profile_tactical_fire_control.py)从本地遭遇只读捕获设计、库存和编队请求，冻结为[输入](../../artifacts/tactical-fire-control-f1f2-20260920/fixture.json)；之后只读该文件，在临时目录构建战斗。输入 SHA、环境、运行代码 SHA 及完整分项数据见[结果](../../artifacts/tactical-fire-control-f1f2-20260920/result.json)。原反解器和关闭缓存的对照仅在验证工具中使用，不是产品开关。

样本为双方各一舰、敌方 25 炮／我方 4 炮。每组执行 240 个真实固定步（4 秒模拟时间），报告全程和去除前 30 步后的计时；每四步真实发布／读取一次视图。相同原库存、位置和指令分别运行原解、仅复用、完整优化。另含静止 12 km 可射击、静止 16 km 射程外、移动 100 m/s、持续全速推进、装满待发弹与清空弹药的变体。库存变体保持原有弹种，原未选弹种的武器使用首个合法配方；每个变体内部才作前后比较，不把库存变体之间的差异归因于优化。

以下完整步均值／P95 取第 31～240 步；瞄准均值取全部 240 步。物理步包含既有飞行展示历史记录，发布和读取另计。

| 场景 | 原完整步均值 | 优化后均值 | 原瞄准均值 → 优化后 | 优化后完整步 P95 | 发射／峰值在途 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 16 km，100 m/s，原库存 | 23.32 ms | 11.80 ms | 10.20 → 0.13 ms | 23.31 ms | 6／6 |
| 16 km，100 m/s 起步并持续推进 | 30.59 ms | 13.64 ms | 15.03 → 0.29 ms | 24.88 ms | 7／7 |
| 12 km，静止且可射击 | 30.64 ms | 19.75 ms | 12.00 → 0.21 ms | 30.92 ms | 8／8 |
| 16 km，移动且已装满待发弹 | 13.28 ms | 11.51 ms | 1.16 → 0.02 ms | 23.71 ms | 6／6 |
| 16 km，移动且空弹 | 3.06 ms | 1.76 ms | 1.13 → 0.02 ms | 2.04 ms | 0／0 |

移动原库存样本中，1,350 次求解请求复用 529 次，只实际计算 821 次。只复用时瞄准均值为 6.33 ms，完整步均值 19.00 ms；快速反解进一步降低瞄准成本。16 km 静止样本位于现有炮弹射程外，双方都没有开火或精确求解，只用作空闲对照，不作为炮战性能证据。

全部对照逐步检查目标、状态、累计射击次数与火控品质，并比较最终库存，未发现差异；完整优化与原解的最大炮角差约 `9.75e-10` rad。只复用的自动测试还逐步比较炮角、弹体和库存，完全一致。以上是本机短时受控比较，计时含分项探针开销，不是实际墙钟持续运行或前端帧率验收。

## 精度与回归

[80 项后台测试记录](../../artifacts/tactical-fire-control-f1f2-20260920/tests.txt)覆盖新增 6 项优化测试及既有弹道、自动索敌、普通火炮、近防与观测测试。专项检查包含：

- 全部现有正式炮弹配置，正常／跨层初速、Mach 曲线边界、2,000／5,000 m/s 与寿命内多个时点；反解时间重新按实际 60 Hz 推进，路径误差小于 0.05 m，与旧预测耗时差小于 0.003 s。
- 随机但固定种子的移动目标、平动／炮口旋转继承速度与跨层比例，实际弹道命中预测位置偏差小于 0.08 m；到期前后、零距离、零速度与不可达目标。
- 观测或模块、炮口、继承速度、配置、倍率变化分别不能误复用；失联、目标失效和原有开火条件回归；失败步骤重试必须重新求解。
- 旧“备份火控来源”测试曾把内部指挥机显式当作第二雷达，但遗漏后来引入的射界数据，原对照也报同一缺项。已补齐这个人工测试源的几何定义，不把指挥机改成传感器，也不放宽产品校验。

本轮未改变前端，未替换正在运行的桌面程序；实际页面与后台持续运行联合验收仍安排在 F5。

## 后续重点

16 km 移动原库存样本近防观测均值仍约 8.09 ms，12 km 静止炮战约 15.06 ms；后者完整步均值仍超过 60 Hz 的 16.67 ms 预算。不得据瞄准成本下降宣称少弹过载已解决。

F3 接入装填／待机低成本跟随、短期精确解、稳定有界的错峰调度与观测失效；F4 再处理当前主要剩余成本——基于合法观测的滚动轨迹和撞舰预测共享。继续使用同一冻结输入，补充高射速、同期装填、突变机动和密集目标，再在 F5 验证实际持续运行。
