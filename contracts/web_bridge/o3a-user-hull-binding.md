# O3a：用户船壳与空白舾装

2026-09-07，最小范围完成。O3b 画布与 O3c 武器组另行验收。

## 创建与固定依赖

`editor.create` 新增参数形状 `{kind: "OutfitPlan", resource_id, name, hull_handle}`。`hull_handle` 必须来自宿主打开文件授权，单次消费，并检查选择后文件是否变化。原有两字段新建船壳接口保持兼容。

创建前按既有船壳规则编译并规范化。舾装固定使用这份船壳快照，保存、恢复、撤销和重做均不按外部路径读取依赖，也不以同名同版本的资源包船壳覆盖它。原船壳移动或修改不会自动同步。当前没有重绑和迁移入口；要采用新船壳需新建舾装。

空白方案标记为 `prototype_unbalanced`，模块为空，使用既有普通涂料。先在基底原点安装 CIC，再满足升力等既有规则。非法但结构正确的草稿可持久恢复，不能保存为合法设计文件。表单默认使用快照的基底甲板与区域 ID，支持用户自定义名称。

## 文件与会话版本

- 绑定 `gaotian.outfit-hull-binding/v1alpha1`：严格包含 `interface`、`hull`、`hull_sha256`、`catalog_dependencies_sha256`。
- 舾装文件 `gaotian.outfit-document/v1alpha1`：严格包含 `interface`、`outfit`、`hull_binding`。
- 带快照会话 `gaotian.editor-session/v3alpha1`：在原会话上增加 `hull_binding`。无快照仍为 v2。
- 带快照恢复记录 `gaotian.editor-recovery/v3alpha1`：负载保存绑定及完整历史。旧 v1/v2 继续读取，但版本与绑定字段不相符时拒绝。

内层船壳和舾装继续使用现有规范资源结构；此包装是编辑器文档，不是旧独立编译器的直接输入。后续出航适配必须验证并解包成原始船壳/舾装对。不得提前声称战术侧已支持此文件。

加载会检查船壳内容指纹、规范性、舾装引用的 ID/版本以及目录依赖。恢复还验证所有撤销、重做和最近合法源。拒绝未知版本、附加路径字段、篡改内容和引用错配。沿用现有大小限制。

## 保存与冲突

快照目录指纹覆盖排序后的材料、模块和涂料目录资源描述，不包含资源包船壳。依赖目录变化时拒绝保存/重新加载/恢复，不能静默采用新参数。保存时重新读取磁盘目录；旧无快照舾装保持原有依赖规则。

文件保存使用原有一次性授权、版本检查和原子写入。外部修改舾装目标仍触发冲突。带快照舾装禁止覆盖根资源类型为 `HullBlueprint` 的文件。新版本仅派生舾装版本，固定船壳不变。
