# 战术炮击：自动选敌与武器组操作

日期：2026-09-15。按用户本轮反馈实施，衔接工作包 3a。总体阶段见[首版规划](./tactical-first-release-implementation-plan.md)。

## 行为与操作

- 火炮默认自动选敌：从当前可观测、有效射程、作用层、射界及遮挡条件允许的敌舰中选取最近可攻击目标；有效目标持续保留，失效后重新选择。友舰、离场舰和残骸不进入自动队列。本方其他舰艇也默认自动选敌开火。
- 有效射程使用当前已装弹（空炮使用下一批所选弹）的寿命/阻力参考射程与武器射程上限的较小值；相邻跨层应用同一降速比例。当前目标层必须与炮弹作用层一致，不自动更改作用层。
- 玩家指定整舰或模块后，切换为指定目标策略，射程外等待、观测失效时停止射击，不自动改打其他敌舰。
- “停止开火”清除瞄准及待处理手动射击，保持停火。“恢复自动选敌”切回自动火控并重新搜敌；新的目标命令或明确的手动射击也可恢复对应操作。
- 火炮面板优先显示舾装中保存的武器组。同型号/版本无显式分组的旧设计使用既有确定性默认组；同型号拆开的不同组保持独立。
- 先选择组，再左键点选敌舰或模块即可批量指定。右键本舰炮位选中其所属组，画布高亮整组成员。未选择组时，点击敌舰仍用于选择舰艇，不隐式下令。
- 组命令也支持切换模式、弹种、作用层和手动攻击甲板；手动模式下一次点击为每个成员请求一发，各炮独立验证能否发射。暂停仍可查看或选择组，不能下达射击命令。
- 单炮选择和目标列表放入展开项。单炮设置与其他成员不同时，组面板明确显示混合状态；统一模式和作用层后可在画布整组瞄准。显示组内总余弹/发射数，并可展开查看各炮状态。

手动炮击权限沿用当前旗舰直控边界，未在本轮扩展为任意舰艇直控。其他舰艇的自动火控已启用；完整舰队命令继续在工作包 6 接入。30 毫米当前仍执行对舰炮击，近防弹体威胁排序、理论弹量协调及耐久拦截不属于本轮交付。

## 接口与一致性

`tactical.realtime.gun` 保留原来的场景、暂停代次、连续序号、最新精确重试与权限规则。选择器为 `weapon_id` 或 `group_id` 二选一，命令不允许同时携带两者。`group_id` 在当前旗舰保存的分组内解析，不能用任意成员列表绕过分组。

新命令 `kind: "auto_target", arguments: {}` 恢复自动选敌；`clear` 现在表示持续停火。视图新增 `groups`（舰艇、分组 ID、名称和武器 ID 列表），每炮新增 `target_policy`：`automatic`、`assigned`、`hold`。原 `mode` 仍区分自动火控与手动点射，不将玩家指定目标等同于手动点射。

组内全部成员先校验，再一次发布状态；组内弹药切换先在库存副本逐炮取消不再使用的装填，全部成功才提交。失败不部分修改目标、库存或命令序号；最新同一请求重试不再次消费。损毁、缺电、缺员、弹药、冷却和射界限制依旧逐炮生效，整组下令不保证整组同时发射。

目标发现与锁定分开：候选采样不提前占用火控通道，只为实际选定目标申请锁定。提前量与可攻击性计算复用同一弹道求解，使用周期采样的观测位置、速度和姿态。自动选择、搜索观测和其他战斗状态一并提交；失败的模拟步不泄漏选敌状态。

主要实现：[目标发现与分组](../../backend/high_wilderness_sidecar/tactical_targeting.py)、[炮击运行时](../../backend/high_wilderness_sidecar/tactical_gunnery.py)、[武器组面板](../../apps/desktop/src/tactical/GunControlPanel.tsx)。没有修改保存格式或为现有舰艇补充弹药。
