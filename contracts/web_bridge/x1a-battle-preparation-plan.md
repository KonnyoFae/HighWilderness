## 目标与界面流程

玩家在正式进入战术模式前，逐舰管理货物和统一弹药资源，并选择哪些武器需要预装填、各装何种弹药。流程为“选择舰船 → 管理库存 → 设置武器预装填 → 核对变动并保存准备 → 进入战术模式”。上一场已保存的受损舰也经过同一准备入口，默认保留原库存、待发弹与战损。

本阶段包含实际战前准备界面，不再使用“出航”统称设计编译、库存准备及入战。战略模式未来提供参战舰船、可用物资和部署条件；目前由明确标注的测试调用方提供有限物资及部署预设，不预设战略航行、采购价格、补给距离或舰队调度玩法。多舰准备按当前小规模场景支持范围实施，不据此扩大战术规模。

| 界面区域 | 玩家操作与反馈 |
| --- | --- |
| 舰船列表 | 从已保存的船壳/栖装创建新实例，或选择已有持久实例；逐舰显示名称、战损、准备状态和入战阻塞原因。切舰保留本次准备草稿，不覆盖设计文件 |
| 货物库存 | 按货物种类调整装入/卸下数量，显示当前、变动后数量及共享容积；损管配件如属于货物，列在同一库存中 |
| 弹药资源 | 显示全舰统一弹药资源现量、容量、预装填预计成本和剩余量；后台仍保留各弹药库来源和有效容量，玩家不管理逐口径成品炮弹 |
| 武器预装填 | 逐武器显示当前弹种/待发数、容量、可用配方与批次成本；默认保持现状，可选择预装填武器和弹种，设置合法整批数量，也可按武器组批量设置 |
| 准备汇总 | 按舰显示装卸数量、预装填消耗、生成的待发弹、换弹处置及最终余量；错误定位到舰船/武器/物资，不隐藏失败项或自动更换玩家选择 |
| 保存准备与进入战斗 | 保存明确的准备结果，再用该版本建立战术场景；可不补给、不预装填而保留现状入战。无弹本身不是禁止整舰入战的理由 |

人员、燃料和必要部署条件只显示已有规则所需的状态与错误；本片不扩建完整人员配置器或战略部署界面，战术推进仍不耗燃料。

## 库存与预装填规则

1. 设计定义容量，持久实例保存实际库存。新建实例的初始物资也要记录来源；复制蓝图不补满旧实例、不修复战损。测试供给与舰内库存分开，装入从供给扣减，卸下进入指定接收方；未来可替换为战略物资接口。没有可用供给时仍能管理现有库存并以舰内资源预装填。
2. 弹药库装载受有效资源容量限制，货物装载受全舰共享容积限制；普通弹药资源和武器内待发弹不重复占货舱。战损超容保留原货物，允许卸载、消费、保存和入战；不能要求先清空超额货物。新增装载必须满足容量规则。
3. 预装填复用武器版本化配方：每批消耗 C 点统一弹药资源，装入 N 发；特殊弹同时消耗对应货物。玩家只选择合法整批，不按每发维护后勤库存；同型武器批量选择也要逐武器核对容量、有效状态和供弹来源。
4. 保存准备时完成所选预装填，无需进入战术后等待装填倒计时；在同一事务内消费资源并生成待发弹。入场只读取完成结果，不能再次扣费或再次免费补满。多个武器争用资源时，先给出完整缺口，不能静默只装一部分武器。
5. 默认保留已有待发弹及其弹种，不勾选预装填不表示卸弹。同种弹允许在剩余容量能容纳整批时补装；切换配方不能直接给已有待发弹改名。当前战斗内“换弹先打空”规则继续有效。
6. 战前带弹换装需要独立处置规则。首版采用明确的“弃置现有待发弹并重新装填”：汇总中显示弃置数量，提交前取消不会损失，提交后旧弹不返还资源，新弹照配方扣费。X1a.1 已冻结为 `explicit-discard-no-refund/v1`；X1a.2 已接实际弃置与扣费，离线准备动作不能用于战斗中跳过装填等待。可逆拆弹、退款及混合弹链后置，不得用重复换装制造资源。
7. 界面为弹种选择保留完整配方接口，但仅允许选择已接通实际战斗效果且与武器兼容的弹种；特殊弹效果未实现时显示不可用原因。首版普通弹即可验证全流程；特殊弹启用随其效果切片验收，不用名称替换冒充效果。
8. 保存的“准备选择/后续装填配方”与“已装入弹种和数量”分别记录；前者不保证未来资源充足，后者才决定当前能发射的弹药。瞄准、目标和锁定仍在新战斗重置。

## 草稿、保存与入战边界

- 准备草稿绑定参战实例及其修订，仅预览变化；每个准备会话覆盖保存一份草稿，不因每次修改累积新副本。重开时核对来源版本，陈旧草稿不能覆盖新战损或库存。
- “保存准备”一次核对全部参战舰、供给来源和操作成本，原子提交实例修订、供给变动、预装填结果及摘要。任何失败全部回滚；稳定请求身份保证重试、回执丢失及重启后不会重复扣费。
- 准备提交成功后，即使场景创建失败也保留已准备好的状态，提示“准备已保存，入战失败，可重试”；再次创建只使用原结果，不重复装填。不需要把长期准备存储与场景运行强行合成同一事务。
- 有未提交战后结果、正在其他战斗中使用或版本冲突的舰船不能被准备操作覆盖。损毁武器不能预装填；入战资格沿用已定义能力规则，不引入额外的“必须满弹/满货”条件。
- 战前装卸、预装填及弃置有独立摘要。战斗资源统计从准备提交后的真实入场值开始，战前成本不重复算作本场开火消耗。战后仍只默认完成已经开始的有效装填；下一次额外预装填由玩家在准备阶段选择。
- 构造、版本、资源、容量和几何的完整校验放在准备提交/入场边界。既有货物变化不动态改变飞行质量的政策单独标注；需要适配初始装载质量时在入场编译处理，不把整舰验证带回实时循环。
