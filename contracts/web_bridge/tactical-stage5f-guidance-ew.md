# 5f：导引头、数据链与电子对抗

日期：2026-09-17。状态：初版已接入真实战术交战、准备、库存结算与界面。后续进入 5g 自动拦截与进阶防御；全目录联合平衡仍属于 5h。

## 已实现

- 16 个常规工作型号均可实际发射，按型号使用主动雷达、红外、反辐射或雷达／红外复合导引头。专用小型拦截弹仍待 5g；不将它当作普通反舰导弹发射。
- 制导与动力分别运行：中段、搜索、锁定确认、追踪、失锁直飞、记忆跟踪、8 字重搜、数据链引导。动力、速度、过载和总寿命沿用三段飞行；重捕与改攻不重置它们。
- 初次搜索限作用层；已锁定对象换层后按其新层天气检查视距，弹体及命中层不变。先选最近的大目标，失锁重捕优先原目标，均须通过实际视距、视锥、信号和遮挡检查。
- 反辐射只自主捕获正在工作的敌舰雷达信号或当前型号主动诱饵的信号。雷达关闭或战损失效立即失去该信号，重新出现时允许在视锥中重捕。
- 失锁后的目标位置只来自最后有效观测。普通型号直飞并保持接收；进阶型号记忆飞行，随后沿 8 字参考路径搜索，实际轨迹仍受转向能力约束。
- 支持数据链的导弹可由工作中的友舰指挥机／数据链接力更新，在“导弹／火控”页改攻作用层内的有效敌舰目标。更新使用真实观测、有效来源和通信距离；数据链情报不会伪装成弹载导引头锁定，通信中断后只使用最后合法样本。
- 箔条／热能烟雾各有大小两型；另有一型主动诱饵发射器。五型均为纯露天外挂、无需人员、无需内部格，也不计算炮塔水平射界。真实编辑器目录放置、保存和重开已验证。
- 干扰弹复用现有待发弹、材料预留、装填、冷却和战果账目，弹药点数费用为零，但须支付工程材料；主动诱饵另需涡喷零件。不能免费装填，也不会额外消耗炮弹材料。
- 战前画布点选后跳转“设备”，可补满单具或本舰同类干扰发射器。战中在“设备／火控”页手动投放；主动诱饵可指定相对舰艏的任意角度。AI 发现导弹后必然投放可用设备，遵守装填、冷却和资源限制。
- 烟云留在投放原地，诱饵实际移动。导弹可以实际转向追踪诱饵；碰到诱饵后导弹和诱饵消失，无舰体后续伤害。碰撞与舰体命中、近防拦截和寿命结束按时间顺序处理。
- 战场显示同层烟云范围和诱饵位置、方向；在途面板显示制导状态、更新来源和剩余寿命。装填与导弹库收在可展开区域中。
- 失败的模拟步骤不会提交投放、库存或改攻；精确重复命令不重复消耗。结算清除烟云、诱饵与在途导弹，保留实际库存消耗；旧存档仍按原政策和目录指纹恢复。

## 已确认边界与可调初值

本轮三项边界均已确认：烟云在本层部署并影响敌我视线，主动诱饵可以明显更强的信号夺取已有锁定，半主动／旧光电实战型号列为后续扩展。具体数值仍为可调初值：

| 项目 | 当前初值／处理 |
| --- | --- |
| 烟云高度与阵营（已确认） | 在发射舰当前层部署，敌我双方均受影响；跨层视线只检查观测端和目标端所在层的区域 |
| 主动诱饵竞争（规则已确认） | 在有效视距和视锥内比较信号强度，信号明显更强时可夺取已有锁定，失锁重捕仍优先原目标。首版数值：信号按距离平方衰减，诱饵超过当前目标 1.5 倍时允许转锁；同档候选确定性排序，无一次性必定诱骗 |
| 复合抗性 | 单箔条或单热烟不失锁，同一视线同时遭两类区域遮挡才失锁；当前主动诱饵能同时模拟两个通道 |
| 进阶失锁能力 | 全部复合型号及中型主动雷达／反辐射型号采用记忆重搜并支持数据链；其他首批型号直飞重捕。能力写在每个型号配置中，可独立修改 |
| 记忆与确认 | 记忆 10 秒；进阶确认 0.1 秒、基础即时确认；反辐射记忆最后辐射位置，其他型号按最后速度外推 |
| 8 字参考搜索 | 半径 1.5 公里、参考周期 30 秒；是转向目标路径，不强制覆盖真实航迹，不能突破过载与低速能力 |
| 小型烟云 | 半径 300 米、45 秒；装填 20 秒、2 份工程材料 |
| 大型烟云 | 半径 800 米、90 秒；装填 20 秒、6 份工程材料 |
| 主动诱饵 | 180 米/秒、90 秒、信号基准 8；装填 30 秒、8 份工程材料及 2 份涡喷零件；实际弹体碰撞半径 1 米 |
| 再次投放 | 烟云间隔至少 20 秒、诱饵至少 30 秒；仍须有有效导弹观测和实际待发弹。AI 可同时使用各具设备 |
| 数据链 | 有效样本最多 0.5 秒；使用现有 100 公里通信范围，信号／设备失效立即停止实时更新 |
| 半主动与旧光电（已确认） | 另列后续扩展，本阶段完成主动雷达、红外、反辐射和复合四类；保留既有含义与接入约束。旧 `passive_radar` 不能重新解释为反辐射，数据链不能代替半主动照射 |

普通反舰候选中的舰艇当前均归“大目标”；主动诱饵也模拟大目标。更细的舰型信号特征、不同抗诱骗能力与搜索参数联合标定留在 5h。上述物理值是游戏初值。

复合导引头原目录的 0.8 战斗部比例现在也作用于实际爆炸伤害和燃烧强度。

## 版本与主要入口

- 新增 `战术电子对抗目录.v3.json`（五个原型均版本 1）和准备政策 v14；v12/v13 等已发布数据不改写。明确的 v12→v13 弹药迁移工具固定读取 v13，不因后续政策升级改变迁移范围。
- `tactical-missile-flight.5f.json` 保存型号制导初值；`tactical-ew.5f.json` 保存五型设备参数及精确原型指纹；可由 `tools/generate_tactical_ew_catalog.py` 重建。
- `missile_guidance.py` 隔离实际感知与记忆／数据链样本；`tactical_ew.py` 在候选战斗事务中投放；`tactical_missiles.py` 接受在途改攻。
- `tactical.realtime.countermeasure` 与导弹改攻均经过宿主白名单、运行状态、命令序号与己方权限检查。
- 新目录设计“电子对抗与复合制导测试舰”可在战前直接导入；原有舰艇不会被自动加装设备。VLS 可在战前选择常规导弹型号。
