## 已确定的范围

| 范围 | 实施必须遵守 |
| --- | --- |
| 准备画布 | 共用画布同时显示敌方在上、我方在下，分页只切编辑方；左侧选方导入，加载即时提示、成功自动生成；右侧火炮/导弹/设备/损管/货舱，点模块自动跳页 |
| 准备操作 | 可调整双方多舰排布并设置测试初始交战距离；单部件和本舰全部同类补满；工程材料战前维修；扩充测试货物种类/数量并处理旧测试环境；保留清空进度入口 |
| 首批内容 | 两档尺寸 × 火箭/涡喷 × 主动雷达/红外/反辐射/复合，共 16 个常规工作型号，另 1 个专用小型拦截弹；8 个小型炮塔式、1 个通用 VLS、基础/进阶自动拦截发射器各 1 款 |
| 配套装备 | 外部火控雷达/IRST、内部指挥机、指挥机上的数据链附加设备、单型号导弹库、自带传感器/计算能力且增重的近防进阶型号；大/小箔条、大/小热能烟雾及首版主动诱饵共 5 种干扰发射器 |
| 动力 | 助推固定方向；主动力和无动力转向均按每 1G·秒损失 9.8 米/秒，主动力提供补偿；无动力直飞不加阻力，熄火不自毁。总寿命为助推＋主动力＋作用层无动力时长 |
| 高度与天气 | 只能本层/相邻层发射、唯一作用层不随目标变化；跨层降低速度及该次速度上限，寿命不额外缩短。导引感知按目标当前层天气重评估，不能因此跨层命中 |
| 制导 | 目标/地点两种发射，预计进入有效发现距离才开机，近距立即搜索但助推不转向；搜索优先最近大目标、失锁优先原目标，按型号区分直飞、记忆、8 字重搜与数据链 |
| 火控与共享 | 雷达/红外提供有效观测，指挥机处理；每雷达跟踪占额度、停止释放；一部有效数据链即可共享，备份可接替；本舰传感器全失效仍可用友舰数据，实际照射要求保留 |
| 电子对抗 | 箔条/热能烟雾留在原地，视线遮挡使对应通道失锁；复合须双类同时遮挡。主动诱饵可误锁并诱骗全部首版导引头；AI 发现敌弹后必用可用干扰装备 |
| 自动拦截 | 近防范围外的大型高速撞舰威胁默认分配一枚更高伤害的拦截弹；耐久未归零不算成功，原目标被其他武器消灭后可在途换靶；无耐久小弹排除，简化近炸仅扩大拦截判定范围 |
| 装填与仓储 | 每库一种型号，基准并发组装 5 枚而非库存限 5；整装优先、无货回退原料；原料直装卸弹退原配方，整装卸弹完整退库、换头再拆解；需入库而满库时拆解已有弹腾空间 |
| VLS 与消耗 | 每具战前一种型号，容量随弹径变化；多弹有发射间隔。发射即已出膛扣弹，转向中不可改令，目标换层/发射器损毁不取消；延迟不耗动力/寿命，平面出现后开始三段计时 |
| 毁伤与结束 | 实际命中速度算穿透、战斗部算后效，100～500 毫米中型后效更大；库毁含整装/组装中弹药殉爆，首版同舰同甲板、不连锁；战后在途及 VLS 转向中弹已使用、不可返还 |

半主动雷达与旧光电总体目标保留，其与本轮首批组合的关系须在对应制导片明确，不能默默删除或将旧光电上层限制套给新红外。具体型号数值、正式名称和特殊能力不由这张范围表自动冻结。

## 验证方式

- 数据/领域：使用可重复样本验证配方/容量守恒、状态转换、合法情报与固定层、命中时序和模型差异；不为单纯布局文字堆砌测试。
- 碰撞与调度：高速相对扫掠、单次命中/拦截、承诺不提前扣血、原目标先被其他武器击毁、库毁与装填完成同一步，必须有可解释事件顺序。
- 界面与桥接：真实导入慢路径、双视区点选、批量补给、两页目标分配一致、失败/不能操作原因、暂停/退出释放；前端快照不能成为后台模拟的第二个真值来源。
- 保存与兼容：双方独立实例、预览不扣费、重复请求只生效一次、旧设计/字段含义不静默改写；正常战后保存不恢复在途弹。测试实例使用独立目录，运行日志不得堵住人工下一场入口。
- 每片只执行相关检查并记录实际范围；阶段负载持续测量。所有本片必需检查通过且没有新增疑点后停止重复跑同一套测试。
