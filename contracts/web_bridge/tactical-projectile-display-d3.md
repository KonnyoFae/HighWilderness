# D3：导弹状态采样与前端平滑显示

2026-09-21。反舰导弹与专用拦截弹已接入新显示通路，接续D4生命周期清理。用户新增的尾迹外观要求一并排入D4：所有炮弹和导弹尾迹统一黄色、固定1 CSS像素宽，取消粗描边；本阶段尚未改动尾迹颜色与线宽。

## 实现范围

- 当前协议为`gaotian.projectile-stream/d3-v1`。导弹首次出现发送型号、战斗部、是否拦截弹等身份；后续`missiles`批次只追加位置/速度、连续高度/垂直速度、偏航/俯仰及离散状态变化。已接收的轨迹和恒定身份不随每次读取重传，常规导弹不再走`paths/trajectory`。
- 位置曲线沿用D2受约束插值，并将高度纳入同一5厘米三维误差预算。参照每个已提交固定步之间的直线段；后台用曲线控制点给出误差上界，超限补关键点，单步仍超限则退为直线。姿态插值单独限制在0.25度误差内，跨越正负180度按最短角度处理。
- 助推/动力/滑行、归属层、制导/机动状态和目标变化均有提交步号，保留变化前后相邻采样。前端按共同显示时钟取离散状态，不能把最新层级、动力耗尽或改追目标提前显示。发动机火光与弹体朝向使用同一时刻状态，俯仰影响平面箭头投影。
- 后台只记录已经提交的运动，不新增制导决策。命中、拦截与自毁终点沿用真实事件；终点高度和姿态取该次已提交碰撞区间的权威运动片段，不向命中后延伸。效果出现仍沿用固定步提交时刻，未在本阶段改成步内分数时刻播放。
- 导弹后台采样队列最多33点，正常按发布区间压缩；保留约32步恢复窗口和一个前置锚点，状态变化另有上限。前端曲线投影按不可变样本窗口缓存，尾迹按模拟时间生成，暂停冻结，缺读不向未来外推。
- 敌导弹仍只使用有效观测给出的坐标、速度、高度和层级；不会从新缓存取隐藏的制导阶段、目标、完整轨迹或真实出生位置。没有合法观测就隐藏。中途首次启用新流仅从当前提交状态建立导弹曲线，不伪造先前未知高度与阶段。
- 保留普通读取的旧格式兼容，按需从曲线恢复位置轨迹；前端可读取D1/D2录制样本。生产协议已切换到D3，但发布中其他重复组装/复制、完整生命周期和长期预算继续由D4/D5收尾。
