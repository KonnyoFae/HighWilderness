# A2 外飘装甲编辑、安装与数值交付

日期：2026-09-21。接续[A1几何](./hull-armor-a1.md)，本片完成设计和舾装；下一片为A3实际倾角防护与战损持久化。A4气动/RCS、A5联合标定保持后续。

## 玩家入口与画布

- 船壳工具新增常驻“◈ 装甲设计”。点击原边线或外飘斜面选边，也可在边列表中选择；此模式拖动只平移画布，不修改端点。
- 装甲板厚以毫米输入，支持关闭/30°/45°/60°；“应用边装甲”原子提交材质、板厚和倾角，并更新同层镜像边。“本层所有边统一为此配置”一次更新全部区域，不受32条命令批次限制。
- 蓝色为真实外飘投影，金色高亮所选边，红色斜线格为外飘导致的露天禁装格。原结构轮廓保留；编辑上层时可对照下层支撑与禁装区。
- 所有几何来自A1编译结果。画布按端点映射回原始边身份，避免规范化时反向/起点变化后编辑错边；非法草稿不显示过期外飘几何，仍可选原始边调整。
- 适应船壳使用完整外形；船壳与舾装画布共用外形数据。数值区区分结构长宽与含装甲外形长宽。
- 零厚度不能开启外飘；非法承接等错误能定位到区域/边，可撤销和重做。船壳保存重开、舾装绑定保存重开均保留配置。

## 安装与遮挡

- 所有外飘边均不生成侧挂槽；基底层外飘不生成新的内部格或露天格，外飘面不能安装设备。
- 上层斜面只要正面积覆盖下层露天格，就移除整个露天格；边界相切不扣格。内部格不变。派生结果额外提供 `armor_blocked_top_cells`，仅供显示禁装原因，不是另一份安装判定。
- 顶挂净空同时检查上层斜面，侧挂本体及净空检查同层完整外形。绕过画布直接输入非法放置也会失败。
- 火炮、炮塔式导弹发射器和探测设备共用的水平遮挡读取上层完整外形；VLS继续只遵循自身安装/垂直发射规则，不加入炮塔水平射界。

## 数值及本轮确认

用户本轮确认并已实现两项政策：

1. 每区域内部填充装甲扣除 = `min(毛边缘体积－20%结构预留, Σ原边长×5米×板厚)`。不再扣外飘新增板材，也不把外飘空腔增加为货物/燃料容量。
2. 局部装甲耐久按实际板材体积计算，包含归属本边的角部封口；继承既有材料局部耐久系数。封口没有独立或重复耐久身份。

实际表面积×板厚用于质量、装甲体积、建造材料与加工工时。斜面及角部质量分布通过三维表面积分计入绕CIC轴惯量。结构切面负载按截面一侧真实表面面积计算，装甲承载沿用既有等效强度模型：板厚×表面切线长度×板内载荷方向分量×材料强度及原有效系数；竖直极限退化到旧公式。这是原等效承载模型的几何扩展，不是新增有限元或三维弹道。

当前战术结构最大耐久继续只读取内部结构。编译器已有的旧综合耐久代理字段不替代战术结构耐久口径。气动/RCS缓存仍按原规则，留待A4接通；不宣称本片已降低阻力或雷达截面积。

旧版本和关闭外飘的边保留原算术路径。船壳v4编译接口为 `gaotian.hull-compiler/a2-v1`，统一表面接口不变，集成阶段改为 `installation_and_mass`；旧蓝图不会因读取自动升级。
