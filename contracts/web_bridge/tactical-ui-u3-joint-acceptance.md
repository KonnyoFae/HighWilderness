# U3：画布 UI 联合验收

日期：2026-09-20。状态：同层／跨层四舰联合操作、连续两场恢复与后台回归均通过，UI 工作包 U 已完成本轮约定范围。下一步为工作包 F；火控求解优化不混入本轮界面收尾。

## 本轮修正

1. **战场超出窗口导致点击面板时整页滚动。** 原战场高度使用固定窗口扣减值，没有计入流程栏及外层间距，点击底部旗舰操纵标签会让画布整体上移约 10 像素。现在战斗阶段由实际可用空间分配高度，面板内容在内部滚动；打开／收起面板不改变画布矩形或镜头。结算、准备保留正常页面滚动，连接诊断在交战时使用覆盖式展开。
2. **导弹性能重复折叠。** 发射页原本在已有的“飞行性能与探测距离”外又包了一层折叠；移除外层，一次展开即可查看。

## 已执行的真实操作

- 双方各两舰，使用隔离的有限库存，从准备画布进入战斗。新版火控父层锁定目标，切换导弹子页后目标仍可见，再显式分配给当前舰艇的发射器并单发。
- 查看真实飞行参数与在途导弹；在有效锁定后使用声明的敌舰换层测试事件，验证实际导弹下潜与碰撞层变化、寿命不刷新。敌方干扰延迟仅是该跨层样本的初始测试条件。
- 自动拦截弹、近防炮射击、50 毫米炮击、玩家与 AI 干扰、数据链共享同时运行。使用声明的第 20 秒储罐故障触发真实下坠，点击警报自动选择受损友舰、展开原已折叠的舰务损管页，玩家启动损管后实际消耗有限资源完成抢修。
- 暂停后导弹和损管命令禁用；货舱、导弹后勤和战场记录可达。在 1920×1080 与 1366×768 验证画布位于窗口内、没有整页横纵滚动，面板及旗舰操纵区开合不改变画布矩形和镜头。
- 同层场景额外验证近防炮实际弹体碰撞拦截；1366×768 下选旗舰炮组，暂停时禁用命令，开始后关闭／恢复自动近防都真实写入该组武器状态，切回友舰继续操作。
- 连续性样本通过界面发射导弹、数据链改攻、启动一批五枚组装；结束战斗时同时保留在途弹、已经出膛但尚未出现的 VLS 弹，以及未完成作业。两种已发射弹均已消耗，不返还。
- 真实 SQLite 写入故障下保存保持原子性并阻止进入下一场；重启恢复未保存战果，丢失成功保存回执后重新查询，不重复扣费。继续准备可完成剩余作业，第二场具有新的飞行状态，双方两场结果再次重启后保持一致。
- 清空确认取消保留进度；清空成功但回执丢失时使用同一请求身份重试；清空后能重新配置舰队进入新战斗。正在运行的战局也可直接放弃，不要求先保存、不产生可恢复战果，旧场景请求被拒绝。
