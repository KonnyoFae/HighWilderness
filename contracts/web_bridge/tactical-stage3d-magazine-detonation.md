# 3d：弹药库殉爆

日期：2026-09-16。接续 [3c 火灾](./tactical-stage3c-spatial-fire.md)，完成首版弹药库殉爆及库存、毁伤和保存衔接。下一片为 3e 人员伤亡与岗位效能；工作包 3 和完整战术首版尚未全部完成。

## 已确认规则

- 空库不殉爆；爆炸消耗该库实际剩余弹药资源，威力随余量变化，只伤及同舰同甲板附近区域。
- 本轮确认：**只有被摧毁时触发**。受伤或燃烧但仍有耐久时，不另抽殉爆概率；炮击和内部火灾均可通过实际毁伤把弹药库摧毁。
- 本轮确认：**首版不连锁殉爆**。先选择本步被直接毁伤摧毁的弹药库，再统一加入爆炸伤害。被这些爆炸摧毁的其他库不会在本步或下一步补爆；同一步被独立直接毁伤摧毁的多个库仍各自结算。

## 结算与空间规则

在固定步中，原有炮击与旧火灾先计算直接损失，随后选择从有耐久降至零、且实际库存非空的弹药库。殉爆与原损失合并，设备、供电/人员许可、船壳和升力失效由既有领域统一结算。殉爆不是玩家可以直接提交的库存命令。

爆心取弹药库在起爆甲板实际占用格的中心。炮击采用致命命中的甲板，火灾采用致命火点的甲板；没有空间来源的既有设备损伤采用安装基准甲板。跨甲板模块仍只在一个起爆甲板产生一次爆炸，余弹不会按占用甲板重复使用。

周边模块按该甲板最近占用格计算距离，同一爆炸对同一模块只计算一次；局部装甲按边线距离，填充燃料槽按其实际多边形距离结算。船壳以该舰既有总结构耐久作统一回写。不同甲板或其他舰艇不受爆炸直接伤害。没有新增舱壁遮挡、爆炸引火、温度积累、概率殉爆或人员伤亡规则。

库存结算在本步装填完成前进行：

1. 已预留但尚未完成装填的弹药仍在库内，与未预留部分一起消耗。
2. 只要装填批次使用了该库，就取消整个批次；释放其他弹药库及特殊货物的预留，不消耗它们。
3. 已装入武器的待发弹保留，不随弹药库消失；后续开火仍须满足武器存活及既有火控许可。
4. 资源账本单列“弹药库殉爆”，保存后的库存和模块战损不自动恢复。被爆炸波及毁坏但不殉爆的其他库保留账面余量，并按现有毁坏库规则不可用于装填；不存在隐式补爆。
5. 已保存为毁坏的弹药库在再次入场时不是新的摧毁事件，不追溯引爆。失败固定步不会提交弹药损失、爆炸记录或任何附带伤害，重试按原状态处理。

## 可调初值

独立配置见[殉爆策略](./fixtures/tactical-magazine-detonation.3d.json)。令 `Q` 为该库实际剩余弹药资源，均为调试初值：

| 参数 | 当前值 |
| --- | --- |
| 半径 | `4 × Q^(1/3)` 米；50 点约 14.7 米 |
| 模块/燃料槽中心伤害 | `4 × Q` 耐久点 |
| 装甲中心伤害 | `2 × Q` 局部耐久点 |
| 船壳损失 | `10 × Q` 结构耐久点，除以该舰最大结构耐久回写 |
| 距离衰减 | 模块、装甲、燃料槽按 `max(0, 1 − 距离/半径)` 线性衰减 |

伤害按目标实际剩余耐久封顶。爆炸事件保留最近 32 条及本场总次数；每条包含起爆库、甲板、高度层、余弹、半径、爆心和实际模块损失。画布显示短时爆炸圈，按事件高度层过滤，暂停时冻结；“战场记录与全舰资源 → 毁伤记录”可查看明细，结算表显示弹药损失原因。
