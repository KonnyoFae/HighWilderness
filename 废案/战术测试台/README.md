# 战术测试台（废案）

状态：**废案 / ABANDONED**。归档日期：2026-09-13。

用户确认现有测试入口无法使用，决定将其移至废案。本方案停止维护，不再作为当前测试入口，也不继续执行此前的入口修补和扩展计划。

## 废弃原因

测试台复用了原工作台，未理顺固定技术样例与自建舰准备、入战之间的操作流程。“实验”仍使用固定舰船，准备好的新舰不能从该入口投入使用。场景占用时要求“释放原测试场景”，当前页面却未提供可见的释放操作，造成流程阻塞。

此前通过的类型检查、自动测试和桥接检查仅覆盖各自技术范围，未证明整套入口可供用户完成实际测试；不能据此将测试台登记为可用。

## 保留内容

- `源码/`：原启动脚本、页面、宿主命令、样本工具及其测试，保留原目录结构并附加 `.txt`，避免参与构建或测试发现。
- `测试台应用接线.patch.txt`：已撤除的应用与宿主接线，供历史查阅。
- `原测试台说明.md.txt`：旧说明快照，启动和操作指引均已失效。
- `未完成入口修复.patch.txt` 及 `源码/apps/desktop/src/tactical/legacyScene.ts.txt`：废弃决定前未完成、未验证的修补，不是可交付实现。

原 `.local/testbench` 测试存档与问题记录保留，归档操作不修改玩家设计或存档。模块战斗接入修复、模块制作 Checklist、后台专项与已有验证记录继续保留，各结论仍受原验证范围限制。O4 已完成状态、取消两小时测试及单场战术最大预期不超过 15 分钟的设计目标保持有效。

当前没有可用的统一人工测试入口；依赖该入口的操作验收等待新的入口方案。此次归档不建立替代测试台，也不自动延续本废案的功能需求。待测范围见[当前测试清单](../../contracts/web_bridge/current-tactical-test-plan.md)。
