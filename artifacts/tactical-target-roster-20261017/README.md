## 每场证据

`verification/<场景>/` 中包含：

- `source.json`：生产文件指纹、固定参照文件哈希、验证器哈希及运行环境。
- `verification.json`、`expanded-tape.json`：900 步、18 类权威状态的新旧比较及摘要。
- `publications.json`：227 次公开读取的新旧匹配摘要。
- `roster.json`：每步独立核对名册与真实活动实体，以及按阵营/层筛选后的顺序；统计元数据变化与原对象复用次数。

纯炮和混合均保留原武器、观测和电子战规则。名册检查在候选版本每步成功提交后执行，旧版本不接入名册。无变化名册的复用次数是结构检查，不能换算为运行速度提升。

证据校验首轮因 JavaScript 校验器未使用现有 Python 契约的缩进和末尾换行，报告摘要不一致；修正校验器的序列化格式后全部通过。模拟结果和已生成的原始证据未改写。

## 交付边界

名册未替换侦测入口，也未向公开响应或 UI 增加目标列表。当前检查证明生命周期与原战斗状态保持一致；后台性能测量随 P2a.1b 读取改造进行，新增列表的发布和界面成本随 P2a.1c/1d 验收。固定 1×、命令显示 250 ms、完整战斗和原生窗口的既有验收缺口继续保留。
