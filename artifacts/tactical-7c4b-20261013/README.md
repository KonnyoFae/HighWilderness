# 7c.4b 自动降速证据

参考提交 `4cb15c04d40f9ed68f06c8fbca949b9c5c0c6986`，采样工作树包含此前完成的 7c.4a 与本片 7c.4b；两片代码、工具和证据在本次提交一并归档。

- `verify-<case>/`：六套 7b 冻结输入，在固定 1× / 固定 0.5× / 自动变速下逐步比对原摘要和 7c.4a 扩展的 18 类状态，各 900 步。自动模式注入成本变化；合成时钟耗时不作为性能数字。
- `paced-<case>/`：六套场景真实时钟、完整发布/读取/编码成本，固定与自动模式依次运行，900 步 / 保护 / 180 现实秒上限。与页面、回归和其他性能进程分开。每份报告包含每种速度的活动停留时间、最长步骤、欠算和保护原因。
- `live-<case>-<variant>/`：四类场景、固定/自动两模式的真实页面通路。每场最多 30 现实秒，自动模式包含 6 次实际操纵。`running.png` / `battle.png` 为运行/暂停截图；`browser.json` 分开记录 Node 往返、页面桥接、解析/合并/采样/绘制及命令回执、DOM 和权威步画布提交时间；`backend.json` / `speed.json` 记录实际运行和速度停留。所有延迟是现实毫秒。画布指标是提交绘制命令的时点，不是 GPU 显示完成或原生窗口体验。
- `validation.json`：59 项后台、206 项前端、类型检查及独立协议/进程检查结果，包含开发期间失败与修复记录。
- `validated-source.json`：最终复核涉及的来源文件指纹；`audit.py` 核对状态、来源与结果并生成 `summary.json`。
- `smoke-mixed/`：早期 24 步检查。
- `smoke-live-mixed-4v4/`：脚本未展开操纵面板导致等待超时。
- `smoke-live-mixed-4v4-r2/`：暴露旧 2 步操纵时点过期；旧测量脚本将重复序号的早期拒绝错误关联到后来成功回执，故其中指令延迟不可用，完整原始记录保留。
- `smoke-live-mixed-4v4-r3/`：前端提前量修正后 6 次操纵成功的开发复验。

全部 smoke 记录排除于正式结论，部分与回归或状态核对并行。状态核对早于前端操纵修正，审计只豁免这三份 UI 文件在早期来源中的差异；模拟/调度来源和冻结输入必须一致。正式计时与页面文件要求完整来源及工具指纹一致。旧 7c.4a 证据保持原样，不能用当前 7c.4b 源码重新声明旧源码指纹未变。

降速运行与固定 1× 通过分开；未达到的命令/画面延迟目标如实保留。详细结论见 [实施记录](../../contracts/web_bridge/tactical-stage7c4b-slowdown.md)。
