# 7c.2 航空计算优化证据

输入来自 `../tactical-7b-20261009`，保留原舰艇、库存、机组、部署及指令。参考采用 `c0554da` 的航空函数，参考和候选都保留已完成的 7c.1a 遮挡与 7c.1b 观测优化。所有结果只评估 7c.2 增量。

- `validation.json`：两批回归 146 次执行，去重 136 项；第二批加入第 11 项 7c.2 专项，生产代码不变。
- `validated-source.json`：生产实现、对照工具、冻结参考与测试源码指纹。
- `verify-<case>/source.json`：运行前源码/工具指纹及参考方法语法树核对结果。首场 mixed-9v9 开始后补充了维修完成的测试方法，其他生产/对照源码不变。
- `verify-<case>/verification.json` 与 `expanded-tape.json`：900 步、18 类权威状态对照、原 7b 摘要核对和诊断计数。
- `measure-<case>/`：关闭计数/分析器，串行 AB/BA/AB 三组独立计时；每次恢复相同战局并清空共享物理预测缓存。分别记录步进、发布、读取、服务 CPU 和服务调用总墙钟耗时。
- `summary.json`：对照、代码/摘要重新哈希核对及配对计时汇总。

`Work` 为航空完整库存候选构造次数，`receiving` 为完整接收投影次数，`can_receive` 为只读资格判断次数；`<module>.deepcopy` 仅统计该模块的外层复制请求，不是递归复制数量。`countdown` 是轻量倒计时的尝试次数，不能据此推定全部命中快路径。诊断不用于正式计时，诊断可与其他正确性检查并行。

仍是离线 15 模拟秒窗口，不代表固定 1× 实时通路、完整战斗或原生 GPU 验收；自动降速未在本片实现。范围和最终结果见 [7c.2 实施记录](../../contracts/web_bridge/tactical-stage7c2-aviation.md)。
