# P2a.1d 名册与目标列表联合验收

日期：2026-10-21。以已推送的 `540c2df` 为当前版本，已完成 P2a.1d 本片联合验收。本轮只增加测量工具、证据和规划，不改变生产逻辑或战斗规则。功能与来源校验通过；整体稳定提速、固定 1× 和 250 ms 目标仍未通过。

## 测量安排

- 联合回归覆盖名册、侦测、目录、航空、电子战、箔条、候选隔离、碰撞和实时发布。生产代码未变时，通过来源校验复用 1b/1c 已完成的六场完整对照；新增计时仍逐步校验原冻结战斗摘要。
- 两种 9 对 9 场景各三组串行交替运行，三种后台范围分别为 `reference`（固定 `352f3e5` 的侦测与旧发布）、`backend`（新侦测与旧发布）、`full`（新侦测及目录摘要）。记录步进、发布、读取、编码、字节、CPU 和总调用用时。
- 同输入分项诊断单列目录投影与 JSON 编码成本；真实服务单列固定 1× 和自动降速，按相同 900 步比较完成时间。
- 浏览器覆盖 1366×768、1920×1080。真实交战页面检查运行与操纵反馈；相同观测输入的列表回放单列旧列表、新列表默认折叠与展开分页的更新成本、节点数和内存。

自动降速持续运行、页面功能通过和短窗口性能记录均不替代固定 1×、250 ms、完整战斗或原生窗口验收。1e 舰对舰事件驱动侦测仍在本片之后实施。

## 正确性与来源

[后台记录](./unit-tests.txt)：195 项通过，覆盖名册、目录、观测、航空飞行/武器/电子战、箔条、P1b/P1c、换层、离场、接敌与实时发布。[前端记录](./frontend-tests.txt)：50 个文件、217 项通过；类型检查、独立组件生产构建及[应用生产构建](./build.txt)通过。[证据审计](./audit.py)通过，汇总见 [summary.json](./summary.json)。

原 1c 的六场 5400 步、1362 次读取不重复运行：由本目录审计脚本逐文件校验此前的 688 个来源文件，并确认原汇总仍与固定提交一致。新增三版本计时另执行 16200 步，全部逐步匹配 7b 冻结摘要，每场九次运行的最终 18 类权威状态一致；摘要校验不计入性能计时。这里只复用与当前生产代码完全一致的已有功能证据。

计时参照 `352f3e5` **已经包含 1a 名册生命周期**。以下是 1b 侦测读取和 1c 目录发布的增量比较，不是整套名册相对改造前的净收益。参考方法和旧 `view` 从该提交提取，在独立运行中局部替换，退出时恢复；无生产开关。新增的前端测试入口使来源清单从 688 增至 689，原有文件均未变。

合并三组 2700 个步进样本后，参考／后台／完整的 P95 为纯炮 **17.951／22.537／19.987 ms**，混合 **74.982／68.264／70.519 ms**。完整范围的步进尖峰为 54.048／116.241 ms；两场的 P95 仍超过 16.67 ms 预算。

完整范围相对参考的总调用用时：纯炮 **+4.42%**、混合 **−1.81%**；相对仅后台：纯炮 −0.57%、混合 +4.11%。这些是本轮实测平均，**不能认定稳定收益，也不能把完整/后台差值全部归因于目录**。同场不同时段的步进本身也显著波动：混合参考三组均值 38.807／47.705／50.956 ms，纯炮后台第三组 17.311 ms，而前两组为 14.958／15.351 ms。所有组均保留，未删慢样本。分布、CPU 和逐次采样见 [纯炮](./measure-guns/measurements.json)、[混合](./measure-mixed/measurements.json)。本任务未同时运行其他负载测试；沙箱内进程采样无法看到宿主全部进程，不能据此断言外部负载或解释波动。

目录平均 JSON 大小为纯炮 1171 字节、混合 2983.84 字节。包含字段名后，完整响应较后台平均增加 1191／3003.84 字节，即 **0.38%／0.79%**；当前完整响应约 315092／384750 字节。摘要本身不是响应体积的主要来源。

另取每场 76 个状态，每个状态重复 20 次目录投影与单字段编码，均值分别为纯炮 **0.091／0.007 ms**、混合 **0.189／0.017 ms**；投影样本最大值 0.309／0.779 ms。此项是已有同状态元数据的边际成本，不能代替出生/退出时的维护成本，后者已计入上表真实发布。采样期间活动目标最多 9／32 个，历史条目最多 0／7 个，不能推广为大量弹体时的后端容量结果。原始输入和分项记录见 [纯炮采样](./capture-guns/)、[混合采样](./capture-mixed/)。

## 保留决策与下一步

保留当前名册、侦测接入及用户要求的目标界面：功能对照通过，目录响应增量较小，分页解决了密集目标时的大量 DOM 更新。**本轮没有交付可确认的整体提速**，纯炮离线与自动服务回退继续作为未解决项；不能将新 UI 的局部收益、平均值或自动运行完成替代整体性能目标。

完整版本计时中，步进占总调用用时约纯炮 75.9%、混合 87.2%；发布/读取/编码占其余部分。主要计算负荷仍在战斗步进。接续 P2a.1e，先把舰载传感器的判断按舰艇、飞机、弹体与雷达/红外拆分，确认舰对舰关系复用的实际收益空间，再实现事件局部更新和约每秒模拟时间分批校验。历史 680313 次不是纯舰对舰次数。保持现有观测采样、发现/失联时机、箔条和电子战规则；若需要简化或允许延迟，另行沟通。

下一片沿用冻结场景，继续复查本轮纯炮回退，分别计入缓存维护、事件检查和实际完整判断成本。更广的航空、弹体及链路优化仍按后续顺序实施；1e 尚未在本轮接入。
