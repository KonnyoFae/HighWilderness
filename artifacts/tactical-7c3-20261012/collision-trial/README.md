# 已撤下的碰撞优化试验

本目录只记录中间试验，不是最终交付版本。试验在导弹优化之外，增加扫掠路径的几何列表复用和按甲板最早命中时间跳过更晚求交。

- `source/` 保留受测生产文件、工具、测试和冻结参考的原始字节，路径对应仓库相对路径；`validated-source.json` 可核对这些文件。
- `validation.json`：134 项相关回归通过。
- 六个 `verify-*`：每场 900 步、18 类权威状态对照通过；实际精确线段/格子求交调用数均未减少。
- `measure-guns-9v9/`：独立三组 AB/BA/AB 计时，平均步进耗时变化 +0.28%、−2.13%、+1.70%，无稳定收益。每轮恢复冻结输入、清空共享物理缓存，不带计数或分析器。
- `after-hotspots-mixed-9v9/`：该试验版本的调用归因，分析器耗时不能充当正式计时。

构造的长路径测试能减少求交，但未转化为代表场景的稳定收益，因此不保留额外生产复杂度。最终 `tactical_damage.py` 已恢复原实现；上级目录独立重测最终版本。此试验的 134 项测试不能与最终回归相加作为不同测试数。
